# 分布判断规则标注

## 入口

- 主入口：`fundamental_analysis/confidence_engine.py`
- 分布核心：`fundamental_analysis/distribution_analyzer.py`
- 解析来源：`fundamental_analysis/confidence_parser.py`

## 核心权重

- 近一场 + 主客场转换：主权重
- 本场位最近一次结果：用于“客回主 / 主回客”的遇胜、遇平、遇负对照
- 往绩 + 底层盘口：只做微调，不改大格局

## 单队评估标注

### 本场位

- `_same_venue(...)`
- 处理主场/客场直接延续
- 加入本场位环境质量 `venue_quality`

### 客回主

- `_ke_hui_zhu(...)`
- 先看最近客场结果，再看最近主场结果
- 对应“客回主 遇胜 / 遇平 / 遇负”
- `distance` 表示连续客场后回主场的衰减

### 主回客

- `_zhu_hui_ke(...)`
- 先看最近主场结果，再看最近客场结果
- 对应“主回客 遇胜 / 遇平 / 遇负”
- `distance` 表示连续主场后回客场的衰减

## 底层盘口

- `_apply_handicap(...)`
- 先处理“让方输球 + 受方逼平”的特殊抵冲
- 再处理一般逆分布无效
- 半一及上只在势均力敌或缓冲偏顺时提供赢球支撑点

## 往绩

- `_apply_h2h(...)`
- 使用真实最近往绩顺序，不再用胜率估算“连胜”
- 新增“主场全胜 / 客场全胜”识别

## 这次补充的重点

- 补了“最近一场本场位参照”
- 补了“客回主 / 主回客”的遇胜、遇平、遇负分支
- 修了底层盘口在逆分布里提前返回，导致特殊抵冲不生效的问题
- 把往绩连胜从“估算”改成“真实顺序统计”
