### S7 心理矩阵（欧赔专家模型）

16种情况，融合主客场心理转换：

**到主场（8种）：**
- 上个主场胜 + 客场胜 → 1.15（双保险信心加成）
- 上个主场胜 + 主场胜 → 1.10（连续主场赢惯性）
- 上个主场胜 + 客场负 → 1.05（主场底气还在）
- 上个主场胜 + 主场负 → 1.00（按最近一场）
- 上个主场负 + 客场胜 → 1.05（客场赢修复）
- 上个主场负 + 主场胜 → 1.00（按最近一场）
- 上个主场负 + 主场负 → 0.85（连续输）
- 上个主场负 + 客场负 → 0.80（主客都不行）

**到客场（8种）：**
- 上个客场胜 + 客场胜 → 0.90（连续客场赢）
- 上个客场胜 + 主场胜 → 0.85（主场胜→客场转化打折）
- 上个客场胜 + 客场负 → 0.75（最近客场输冲淡）
- 上个客场胜 + 主场负 → 0.70（信心受挫）
- 上个客场负 + 客场胜 → 0.80（按最近一场修复）
- 上个客场负 + 主场胜 → 0.75（客场阴影+主场胜打折）
- 上个客场负 + 客场负 → 0.60（连续客场输）
- 上个客场负 + 主场负 → 0.55（没有信心：主客双输）

### 平局计算（加法逻辑）
- **旧**：`100 - diff`（从100减，永远偏高）
- **新**：`√(主信心 × 客信心) × 交锋平局修正`（与主/客同一量级）
- 交锋平局修正 = `1 + (draw_freq - 0.20) × 0.8`

### v1.1 含金量系数
- S10之后、S11之前执行
- 取近3场对手联赛排名，判断胜负含金量：
  - 赢了前25%对手 → 1.20
  - 赢了前50%对手 → 1.10
  - 输给后25%对手 → 0.85
  - 输给后50%对手 → 0.92
  - 平局/杯赛/无排名 → 1.00
- 3场取平均

### v1.2 历史交锋动态权重熔断
- 一级熔断（胜率≤20%或≥80%，≥5场）→ 交锋权重0.40
- 二级熔断（胜率≤10%或≥90%，≥5场）→ 交锋权重0.50
- 触发时显示「🔴 历史血脉压制」标签

### 临场基本面分析模块
