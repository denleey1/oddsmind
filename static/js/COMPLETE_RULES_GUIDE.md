# 完整规则指南

## 📊 核心概念

### 信心区间划分

| 区间 | 名称 | 范围 |
|------|------|------|
| **中上** | 好 | > 5.6 |
| **中庸** | 一般 | 4.4 - 5.6 |
| **低** | 差 | < 4.4 |

> **关键分界线**：5.6
> - **中上**（好）= > 5.6
> - **中庸及以下**（一般）= ≤ 5.6（包含中庸和低）

---

## 💪 强队打出规则（3条完全覆盖）

### 规则 C：强队信心中上
**条件**：强队信心 > 5.6（中上）  
**弱队**：任意  
**开盘**：**超实盘**  
**说明**：
- 强队信心很高，必须超实盘
- 初赔低开为认可
- 变盘降至超实区间 = 强队正路打出

---

### 规则 A：弱队信心好
**条件**：强队信心 ≤ 5.6（中庸及以下）  
**弱队**：> 5.6（好）  
**开盘**：**实盘**  
**说明**：
- 弱队信心好，强队中庸及以下可开实盘
- 变盘时可略微升水
- 强队正路打出

---

### 规则 B：弱队信心一般
**条件**：强队信心 ≤ 5.6（中庸及以下）  
**弱队**：≤ 5.6（一般）  
**开盘**：**实盘（中水以下）+ 平分散**  
**说明**：
- 弱队信心一般，实盘需在中水以下
- 必须配合平赔分散投注
- 变盘以降低赔付为主要目的
- 例如：实开中水→实开超低水，或实开低水→超实盘高水
- 强队正路打出

---

## 🎲 弱队打出规则（3条完全覆盖）

### 规则 D：弱队信心中庸以下
**条件**：弱队信心 ≤ 5.6（中庸以下）  
**强队**：任意  
**开盘**：**实开盘**  
**说明**：
- 无论强队如何，弱队想打出必然开在实开盘附近
- 后期盘口水位升至高水
- 且对手（强队）的赔率区间进一步降低
- → 弱队正路打出（冷门）

---

### 规则 E：弱队信心中上且强队相当
**条件**：弱队信心 > 5.6（中上）  
**强队**：≥ 弱队（相当）  
**开盘**：**实开盘 + 平赔分散**  
**说明**：
- 弱队信心中上，但强队状态相当或更好
- 开在实开盘，配合平赔分散
- 后期无论变盘升水还是降水
- 弱队依然是正路打出（冷门）

---

### 规则 F：弱队信心中上且强队更差
**条件**：弱队信心 > 5.6（中上）  
**强队**：< 弱队（更差）  
**开盘**：**超实盘**  
**说明**：
- 弱队自身信心足够强，且强队比它更弱
- 弱队想打出，盘口必然要进入超实盘
- 初赔为"实开"或"低开"表示认可
- 变盘后进入"超实盘"
- 若平赔位置在：**平中庸** / **平实低** / **低开平**
- → 弱队稳稳正路打出（冷门）

## 🔄 变盘规律总结

| 规则 | 初盘特征 | 变盘方向 | 正路信号 |
|------|---------|---------|---------|
| **C** | 超实盘 或 低开 | 降至超实区间 | 强队打出 |
| **A** | 实盘 | 可略微升水 | 强队打出 |
| **B** | 实盘中水以下 | 降赔为主 | 强队打出 |
| **D** | 实开盘 | 升至高水 + 对手区间降 | 弱队打出 |
| **E** | 实开盘 + 平分散 | 升/降都可 | 弱队打出 |
| **F** | 实开/低开 → 超实盘 | 进入超实 + 平赔配合 | 弱队打出 |

## 💡 使用技巧

### 1️⃣ 优先看强队规则
- 通常市场倾向于强队打出
- 用澳门一赔（让方区间）验证强队规则

### 2️⃣ 参考弱队规则
- 评估冷门可能性
- 用马会三赔（受方区间）验证弱队规则

### 3️⃣ 双规则都匹配 → 高信心
- 强队规则匹配 ✓ + 弱队规则匹配 ✓
- 说明盘口设计合理，庄家态度清晰

### 4️⃣ 规则冲突 → 需谨慎
- 强队规则匹配但弱队不匹配
- 或弱队规则匹配但强队不匹配
- 需结合拉力、分散、平赔综合判断
