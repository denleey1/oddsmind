# 规则覆盖矩阵

## 📊 完整规则覆盖表

### 强队打出规则（让方）

| 让方信心 | 受让信心 | 规则 | 区间要求 | 说明 |
|---------|---------|------|---------|------|
| **> 5.6** (中上) | 任意 | **C** | 超实 | 让方信心很高，必须超实开盘 |
| **4.4-5.6** (中庸) | **> 5.6** (中上) | **A** | 实开 | 受让强但让方中庸，实开可微升水 |
| **4.4-5.6** (中庸) | **4.4-5.6** (中庸) | **B** | 实开 | 双方中庸，实开中水以下+平分散 |
| **4.4-5.6** (中庸) | **< 4.4** (低) | **B1** | 实开 | 让方优势明显，实开中低水 |
| **< 4.4** (低) | 任意 | **G** | 高开/韬光 | 让方信心不足，保守开盘 |

### 弱队打出规则（受方）

| 受让信心 | 让方信心 | 差值关系 | 规则 | 区间要求 | 说明 |
|---------|---------|---------|------|---------|------|
| **< 4.4** (低) | 任意 | - | **D** | 实开 | 受让低信心，实开观察 |
| **> 5.6** (中上) | **< 受让** | 受让更强 | **F** | 超实 | 受让强且让方更差，必须超实 |
| **> 5.6** (中上) | **≥ 受让** | 让方不弱 | **F1** | 实开 | 受让强但让方更强，实开观望 |
| **4.4-5.6** (中庸) | 接近 | \|差值\| < 0.5 | **E** | 实开 | 双方相当，实开+平分散 |
| **4.4-5.6** (中庸) | **> 受让** | 差值 ≥ 0.5 | **E1** | 低开 | 受让弱于让方，可能诱盘 |
| **4.4-5.6** (中庸) | **< 受让** | 差值 ≥ 0.5 | **E2** | 实开 | 受让强于让方，实开平衡 |

## 🎯 规则优先级判断流程

### 强队规则判断顺序：
```
1. 让方 > 5.6? 
   ✓ → 规则 C (超实)
   ✗ → 继续

2. 受让 > 5.6 且 让方中庸?
   ✓ → 规则 A (实开)
   ✗ → 继续

3. 双方都中庸?
   ✓ → 规则 B (实开)
   ✗ → 继续

4. 让方中庸 且 受让低?
   ✓ → 规则 B1 (实开)
   ✗ → 继续

5. 让方 < 4.4?
   ✓ → 规则 G (高开/韬光)
```

### 弱队规则判断顺序：
```
1. 受让 < 4.4?
   ✓ → 规则 D (实开)
   ✗ → 继续

2. 受让 > 5.6 且 让方 < 受让?
   ✓ → 规则 F (超实)
   ✗ → 继续

3. 受让 > 5.6 且 让方 ≥ 受让?
   ✓ → 规则 F1 (实开)
   ✗ → 继续

4. 受让中庸 且 |差值| < 0.5?
   ✓ → 规则 E (实开)
   ✗ → 继续

5. 受让中庸 且 |差值| ≥ 0.5?
   ✓ → 
      受让 < 让方? → 规则 E1 (低开)
      受让 > 让方? → 规则 E2 (实开)
```

## 💡 使用建议

1. **优先看强队规则**（让方打出）
   - 通常市场倾向于强队
   - 澳门一赔验证强队规则

2. **参考弱队规则**（受方打出/冷门）
   - 评估冷门可能性
   - 马会三赔验证弱队规则

3. **双规则都匹配** → 高信心
   - 强队规则匹配 + 弱队规则匹配
   - 说明盘口设计合理

4. **规则冲突** → 需谨慎
   - 强队规则匹配但弱队不匹配
   - 或反之
   - 需结合拉力、分散综合判断
