# 信心区间划分说明

## 📊 信心值区间定义

| 信心值范围 | 等级名称 | 说明 |
|-----------|---------|------|
| **< 4.4** | **低** | 信心不足，队伍实力或状态较差 |
| **4.4 - 5.6** | **中庸** | 中等信心水平，实力相对平衡 |
| **> 5.6** | **中上** | 较高信心，队伍实力较强 |

> ⚠️ **重要**：4.4 和 5.6 是区间的边界值，而不是单一的阈值点！

## 🎯 强队打出规则

### 规则 C：让方中上信心
- **条件**：让方信心 > 5.6（中上）
- **要求**：必须"超实"开盘
- **说明**：让方信心很高，必须超实才能认可，初赔低开为认可，后续跌入超实=正路

### 规则 A：受让中上 + 让方中庸
- **条件**：受让信心 > 5.6（中上）且 让方信心在 4.4-5.6（中庸）
- **要求**："实开"
- **说明**：实开可微升水

### 规则 B：双方中庸
- **条件**：让方和受让信心都在 4.4-5.6（中庸）
- **要求**："实开(中水以下)+平分散"
- **说明**：变盘以降赔为主

### 规则 B1：让方中庸 + 受让低
- **条件**：让方信心在 4.4-5.6（中庸）且 受让信心 < 4.4（低）
- **要求**："实开"中低水
- **说明**：让方优势明显

### 规则 G：让方低信心
- **条件**：让方信心 < 4.4（低）
- **要求**："高开"或"韬光"
- **说明**：信心不足建议保守开盘，观察市场反应

## 🔄 弱队打出规则

### 规则 D：受让低信心
- **条件**：受让信心 < 4.4（低）
- **要求**："实开"附近
- **说明**：后期升至高水且对手区间更低=正路

### 规则 F：受让中上 + 让方更差
- **条件**：受让信心 > 5.6（中上）且 让方信心 < 受让信心
- **要求**：必须"超实"
- **说明**：平赔∈{平中庸/平实低/低开平}更稳

### 规则 F1：受让中上 + 让方不弱
- **条件**：受让信心 > 5.6（中上）但 让方信心 ≥ 受让信心
- **要求**："实开"
- **说明**：受让虽强但让方更强，实开观望，需看让方态度

### 规则 E：受让中庸 + 与让方相当
- **条件**：受让信心在 4.4-5.6（中庸）且 与让方信心相差 < 0.5
- **要求**："实开+平分散"
- **说明**：后续升/降皆可

### 规则 E1：受让中庸 + 明显弱于让方
- **条件**：受让信心在 4.4-5.6（中庸）且 明显弱于让方（差值 ≥ 0.5）
- **要求**："低开"
- **说明**：可能诱盘，需谨慎

### 规则 E2：受让中庸 + 强于让方
- **条件**：受让信心在 4.4-5.6（中庸）且 强于让方（差值 ≥ 0.5）
- **要求**："实开"
- **说明**：平衡盘面

## 📝 示例

### 示例 1：规则 C
```
主队信心：6.2（中上）
客队信心：4.8（中庸）
让球方：主队
让方信心：6.2 > 5.6 ✓
→ 应用规则 C：必须超实开盘
```

### 示例 2：规则 B
```
主队信心：5.1（中庸）
客队信心：4.9（中庸）
让球方：主队
让方信心：5.1 ∈ [4.4, 5.6] ✓
受让信心：4.9 ∈ [4.4, 5.6] ✓
→ 应用规则 B：实开(中水以下)+平分散
```

### 示例 3：规则 A
```
主队信心：5.0（中庸）
客队信心：6.5（中上）
让球方：主队
让方信心：5.0 ∈ [4.4, 5.6] ✓
受让信心：6.5 > 5.6 ✓
→ 应用规则 A：实开可微升水
```

## 🔍 调试方法

在浏览器控制台查看信心等级：

```javascript
// 运行调试工具
debugRuleAnalysis()

// 查看分析结果中的信心等级
const result = window.MatchRuleAnalyzer.analyzeMatch(window.currentMatchData);
console.log(result.data.debug);
// 输出示例：
// confLet: 5.2
// confLetLevel: "中庸"
// confTake: 6.1
// confTakeLevel: "中上"
```

## 🔧 配置修改

如需调整信心区间阈值，在 `match_rule_analyzer.js` 中修改：

```javascript
CONFIDENCE_RANGES: {
    MEDIUM_LOW: 4.4,    // 中庸下限
    MEDIUM_HIGH: 5.6    // 中庸上限
}
```
