# 激活码和账号有效期完整说明

## 📋 完整机制说明

### 1️⃣ 激活码配置

**数据库字段（invite_codes表）：**
- `account_expires_days`：账号有效期（天数）
- `max_uses`：激活码最大使用次数
- `used_count`：已使用次数
- `expires_at`：激活码本身的过期时间（可选）
- `is_active`：激活码是否启用

**示例：**
```sql
-- TEST1D: 1天有效期，只能使用1次
INSERT INTO invite_codes (code, max_uses, account_expires_days, is_active)
VALUES ('TEST1D', 1, 1, TRUE);

-- VIP365: 365天有效期，可使用10次
INSERT INTO invite_codes (code, max_uses, account_expires_days, is_active)
VALUES ('VIP365', 10, 365, TRUE);
```

### 2️⃣ 激活流程

**用户激活时：**
```python
# 1. 验证激活码（检查使用次数、激活码过期时间）
# 2. 计算账号过期时间
account_expires_at = datetime.now() + timedelta(days=expires_days)

# 3. 激活用户并设置过期时间
UPDATE miniprogram_users
SET is_activated = TRUE,
    activated_at = NOW(),
    expires_at = %s,  # ← 这里保存的是账号过期时间
    invite_code_used = %s
WHERE openid = %s
```

**效果：**
- 用户使用 TEST1D（1天有效期）激活
- `miniprogram_users.expires_at` = 激活时间 + 1天
- 例如：2025-11-16 12:00 激活 → 2025-11-17 12:00 过期

### 3️⃣ 登录验证

**每次登录时：**
```python
# 1. 检查是否激活
if not is_activated:
    return error("需要激活账号")

# 2. 检查账号是否过期
if expires_at < datetime.now():
    return error("账号已过期，请联系管理员")

# 3. 生成token，允许登录
return success(token)
```

**流程图：**
```
用户登录
    ↓
检查 is_activated
    ↓ 未激活
返回"需要激活"
    ↓ 已激活
检查 expires_at
    ↓ 已过期
返回"账号已过期" ❌
    ↓ 未过期
返回 token，允许登录 ✅
```

## 🔧 管理操作

### 查询用户过期时间

```sql
SELECT id, 
       SUBSTRING(openid, 1, 15) as openid_prefix,
       is_activated, 
       activated_at, 
       expires_at,
       invite_code_used,
       CASE 
         WHEN expires_at IS NULL THEN '永不过期'
         WHEN expires_at > NOW() THEN CONCAT('有效(还剩', TIMESTAMPDIFF(HOUR, NOW(), expires_at), '小时)')
         ELSE '已过期'
       END as status
FROM miniprogram_users 
WHERE is_activated = 1
ORDER BY expires_at;
```

### 延长用户有效期

```sql
-- 延长用户6的有效期30天
UPDATE miniprogram_users
SET expires_at = DATE_ADD(expires_at, INTERVAL 30 DAY)
WHERE id = 6;
```

### 设置永不过期

```sql
-- 设置用户为永不过期（VIP用户）
UPDATE miniprogram_users
SET expires_at = NULL
WHERE id = 1;
```

## 📊 两种过期时间

### 1. 激活码过期时间（invite_codes.expires_at）

**作用：** 控制激活码本身的有效期
- 如果设置了，激活码在该时间后不能使用
- 如果为 NULL，激活码永不过期

**示例：**
```sql
-- 创建一个7天后过期的激活码
INSERT INTO invite_codes (code, max_uses, account_expires_days, expires_at, is_active)
VALUES ('PROMO2025', 100, 30, DATE_ADD(NOW(), INTERVAL 7 DAY), TRUE);
```

**效果：**
- 2025-11-16 创建
- 2025-11-23 后，该激活码无法使用
- 但已经用该激活码激活的用户不受影响（他们有30天账号有效期）

### 2. 账号过期时间（miniprogram_users.expires_at）

**作用：** 控制已激活账号的有效期
- 用户激活时，根据 `account_expires_days` 计算
- 登录时检查，过期则拒绝登录

**示例：**
```
用户A 2025-11-16 用 TEST1D（1天有效期）激活
→ expires_at = 2025-11-17
→ 2025-11-17 后登录 → ❌ "账号已过期"
```
