# 激活码使用限制和登录流程说明

## ✅ 系统已实现的功能

### 1. 激活码只能使用一次

**实现机制：**

1. **数据库字段：**
   - `max_uses`：最大使用次数（默认1）
   - `used_count`：已使用次数（默认0）

2. **创建激活码时：**
   ```python
   # tools/manage_invite_codes.py
   def create_invite_code(
       code: Optional[str] = None,
       max_uses: int = 1,  # ✅ 默认只能使用1次
       ...
   ):
   ```

3. **验证激活码时：**
   ```python
   # utils/miniprogram_db.py
   def validate_invite_code(code: str):
       invite_info = get_invite_code(code)
       
       # ✅ 检查使用次数
       if invite_info['used_count'] >= invite_info['max_uses']:
           return False, "邀请码使用次数已达上限"
       
       return True, None
   ```

4. **使用激活码时：**
   ```python
   # application/routes/miniprogram.py
   # 激活成功后，增加使用次数
   use_invite_code(invite_code)  # used_count + 1
   ```

**流程：**
```
创建激活码 (max_uses=1, used_count=0)
    ↓
用户激活 (验证: used_count < max_uses) ✅
    ↓
激活成功 (used_count = 1)
    ↓
再次使用 (验证: used_count >= max_uses) ❌ "使用次数已达上限"
```

---

### 2. 激活后下次登录直接进入

**实现机制：**

1. **激活时保存状态：**
   ```python
   # utils/miniprogram_db.py
   def activate_user(openid: str, invite_code: str, expires_days: int):
       sql = """
           UPDATE miniprogram_users
           SET is_activated = TRUE,  # ✅ 设置激活状态
               activated_at = NOW(),
               expires_at = %s,
               invite_code_used = %s
           WHERE openid = %s
       """
   ```

2. **登录时检查状态：**
   ```python
   # application/routes/miniprogram.py
   @miniprogram_bp.route('/api/miniprogram/login', methods=['POST'])
   def miniprogram_login():
       user = get_user_by_openid(openid)
       
       # ✅ 检查是否已激活
       is_activated = bool(user.get('is_activated'))
       
       if not is_activated:
           # ❌ 未激活，返回需要激活
           return api_success({
               'is_activated': False,
               'message': '需要激活账号'
           })
       
       # ✅ 已激活，直接返回token
       token = issue_jwt_token({...})
       return api_success({
           'token': token,
           'user': {
               'is_activated': True,
               ...
           }
       })
   ```

**流程：**
```
首次登录 → 未激活 → 显示激活界面
    ↓
输入激活码 → 激活成功 → is_activated=TRUE
    ↓
下次登录 → 检查is_activated → 已激活 → 直接返回token → 进入首页 ✅
```


```
   → 后端返回: {is_activated: false, message: "需要激活账号"}
   → 前端显示激活界面

2. 用户输入激活码 TEST123
   → 后端验证: used_count (0) < max_uses (1) ✅

   → 返回token和用户信息

3. 用户再次登录
   → 后端检查: is_activated = TRUE ✅
   → 直接返回token
   → 前端直接进入首页
```

```
   → 后端验证: used_count (1) >= max_uses (1) ❌
   → 返回错误: "邀请码使用次数已达上限"
```

## ⚠️ 注意事项

### 1. 激活码使用次数

- ✅ **默认只能使用1次**：创建时 `max_uses=1`
- ✅ **验证逻辑**：`used_count >= max_uses` 时拒绝
- ✅ **使用后更新**：激活成功后 `used_count + 1`

### 2. 用户激活状态

- ✅ **激活时设置**：`is_activated = TRUE`
- ✅ **登录时检查**：`if not is_activated: return needActivate`
- ✅ **持久化存储**：状态保存在数据库中

### 3. 并发安全

- ⚠️ **当前实现**：可能存在并发问题（两个用户同时使用同一个激活码）
- ✅ **建议优化**：使用数据库事务和行锁（`FOR UPDATE`）

## 🛠️ 优化建议（可选）

### 1. 添加事务支持（防止并发问题）

```python
# 在激活接口中使用事务
from app_database import get_connection

def activate_user_with_invite_code(openid: str, invite_code: str, expires_days: int):
    conn = get_connection()
    try:
        with conn.cursor() as cursor:
            # 使用行锁防止并发
            cursor.execute("""
                SELECT max_uses, used_count
                FROM invite_codes
                WHERE code = %s FOR UPDATE
            """, (invite_code,))
            
            invite_info = cursor.fetchone()
            
            # 验证使用次数
            if invite_info['used_count'] >= invite_info['max_uses']:
                raise ValueError("邀请码使用次数已达上限")
            
            # 激活用户
            cursor.execute("""
                UPDATE miniprogram_users
                SET is_activated = TRUE,
                    activated_at = NOW(),
                    expires_at = %s,
                    invite_code_used = %s
                WHERE openid = %s
            """, (expires_at, invite_code, openid))
            
            # 使用邀请码
            cursor.execute("""
                UPDATE invite_codes
                SET used_count = used_count + 1
                WHERE code = %s
            """, (invite_code,))
            
            conn.commit()
    except Exception as e:
        conn.rollback()
        raise
    finally:
        conn.close()
```

### 2. 添加激活码使用记录

```sql
CREATE TABLE invite_code_usage (
```
