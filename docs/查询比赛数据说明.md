# 查询比赛数据使用说明

本工具提供了两种方式查询某场比赛的完整数据：

## ⚠️ 重要说明

**推荐使用 `query_match_api_data.py`** - 这个脚本调用比赛详情API，返回的数据包含规则值、规则差值等完整的分析数据。

`query_match_data.py` 和 `query_match_data.sql` 是直接查询数据库的版本，可能不包含API中计算出的所有字段。

## 查询内容

1. **基本面数据**：比赛基本信息、球队信息、比分、排名、状态、基本面分析推荐等
2. **赔率分析数据**：实力分析、规则值、规则差值、区间、理论距离、偏移量等（**不含推荐结果**）
3. **实际赔率**：马会、澳门、威廉希尔、平博四家博彩公司的初盘和即时赔率

## 使用方法

### 方法一：使用 API 查询脚本（⭐推荐）

```bash
python query_match_api_data.py <match_id>
```

**示例：**
```bash
python query_match_api_data.py 123456
```

**特点：**
- 调用比赛详情API，数据完整
- 包含规则值、规则差值等所有分析字段
- 自动排除推荐部分
- 输出格式化的JSON文件
- 数据与前端显示一致

**输出：**
- 控制台显示格式化的数据
- 自动保存为 `match_{match_id}_data.json` 文件

### 方法二：使用数据库查询脚本

```bash
python query_match_data.py <match_id>
```

**示例：**
```bash
python query_match_data.py 123456
```

### 方法三：使用 SQL 文件

1. 打开 `query_match_data.sql` 文件
2. 将 `{MATCH_ID}` 替换为实际的比赛ID，或者设置变量：
   ```sql
   SET @match_id = 123456;
   ```
3. 在 MySQL 客户端中执行该 SQL 文件

**示例：**
```bash
mysql -u username -p database_name < query_match_data.sql
```

或者在 MySQL 客户端中：
```sql
source /home/ubuntu/oddsmind/query_match_data.sql;
```

## 数据来源说明

### API 查询方式（推荐）
- **API端点**：`/api/matches/<match_id>` 或 `/api/public/matches/<match_id>`
- **服务类**：`MatchDetailService.get_complete_match_detail()`
- **数据包含**：
  - 基本面分析（fundamentalAnalysis）
  - 所有公司的赔率分析（companyAnalyses），包含规则值、规则差值等
  - 实际赔率数据（从companyAnalyses中提取）

### 数据库查询方式
#### 基本面数据来源
- `matches` 表：比赛基本信息
- `leagues` 表：联赛信息
- `teams` 表：球队信息
- `fundamental_analysis` 表：基本面分析结果

#### 赔率分析数据来源
- `odds_analysis_results` 表：赔率分析结果
- **排除字段**：
  - `initial_recommended_outcome`（初盘推荐）
  - `initial_confidence_level`（初盘信心等级）
  - `current_recommended_outcome`（即时推荐）
  - `current_confidence_level`（即时信心等级）

#### 实际赔率数据来源
- `european_odds` 表：欧洲赔率数据
- `companies` 表：博彩公司信息

## 注意事项

1. 确保比赛ID存在，否则可能返回空结果
2. 如果某个部分没有数据，脚本会提示"未找到数据"
3. 赔率分析数据可能不是所有比赛都有，取决于是否已执行分析任务
4. 实际赔率数据取决于是否已爬取对应博彩公司的数据

## 故障排查

如果查询失败，请检查：
1. 数据库连接是否正常
2. 比赛ID是否正确
3. 相关数据表是否存在
4. 是否有相应的数据记录
