# 数据库错误修复说明

## 问题描述

日志中出现大量数据库错误：
```
Transaction failed: (1364, "Field 'home_team_id' doesn't have a default value")
MatchStatusUpdater - ERROR - 更新比赛 XXX 状态失败
```

## 问题原因

在 `services/match_status_updater.py` 的 `_update_single_match` 方法中，当插入新比赛时，INSERT语句没有包含 `home_team_id` 和 `away_team_id` 字段，但数据库表要求这两个字段必须有值（NOT NULL，没有默认值，且有外键约束）。

## 修复方案

### 1. 添加 `_get_or_create_team_id` 方法

新增辅助方法，根据球队名称获取或创建 `team_id`：
- 先尝试根据球队名称查找现有球队
- 如果找不到，使用球队名称的MD5哈希值生成 `team_id` 并创建新球队记录
- 处理并发创建的情况（使用 ON DUPLICATE KEY UPDATE）

### 2. 修改 `_update_single_match` 方法

在插入新比赛时：
- 获取或创建 `home_team_id` 和 `away_team_id`
- 在 INSERT 语句中包含这两个字段
- 如果无法获取 `team_id`，跳过插入并记录警告（而不是抛出错误）

## 修改内容

### 修改文件
- `services/match_status_updater.py`

### 主要变更

1. **添加导入**：
   ```python
   import hashlib
   ```

2. **新增方法** `_get_or_create_team_id(team_name: str) -> Optional[int]`：
   - 根据球队名称查找或创建 `team_id`
   - 使用MD5哈希生成稳定的 `team_id`
   - 处理并发创建冲突

3. **修改 `_update_single_match` 方法**：
   - 在插入新比赛前，获取 `home_team_id` 和 `away_team_id`
   - INSERT 语句包含这两个必需字段
   - 如果无法获取 `team_id`，记录警告并跳过插入

## 预期效果

修复后：
- ✅ 插入新比赛时不再出现 `home_team_id` 缺失错误
- ✅ 自动创建缺失的球队记录
- ✅ 比赛记录包含完整的 `home_team_id` 和 `away_team_id`
- ✅ 错误日志大幅减少

## 注意事项

1. **team_id 生成策略**：使用球队名称的MD5哈希值生成 `team_id`，确保相同名称的球队总是得到相同的 `team_id`
2. **并发安全**：使用 `ON DUPLICATE KEY UPDATE` 处理并发创建的情况
3. **错误处理**：如果无法获取 `team_id`，会记录警告但不会抛出异常，避免影响其他比赛的更新
