# 配置参数获取指南

## 📋 需要配置的参数

1. **WECHAT_APPID** - 微信小程序 AppID
2. **WECHAT_APPSECRET** - 微信小程序 AppSecret
3. **JWT_SECRET** - JWT Token 密钥

---

## 🔍 参数获取方法

### 1. 微信小程序 AppID 和 AppSecret

#### 步骤一：登录微信公众平台

1. 访问：https://mp.weixin.qq.com/
2. 使用微信扫码登录（需要小程序管理员权限）

#### 步骤二：进入小程序管理后台

1. 登录后，选择你的小程序
2. 进入"开发" → "开发管理" → "开发设置"

#### 步骤三：获取 AppID 和 AppSecret

**AppID（小程序ID）：**
- 位置：开发设置页面顶部
- 格式：类似 `wx1234567890abcdef`
- 可以直接复制

**AppSecret（小程序密钥）：**
- 位置：开发设置页面中的"AppSecret"
- 如果未设置，点击"生成"按钮
- ⚠️ **重要**：AppSecret 只显示一次，请妥善保存！

#### 步骤四：配置服务器域名（重要）

在"开发设置" → "服务器域名"中，添加你的后端域名：
- **request合法域名**：`https://oddsmind.top`
- **uploadFile合法域名**：`https://oddsmind.top`
- **downloadFile合法域名**：`https://oddsmind.top`

---

### 2. JWT_SECRET（JWT Token 密钥）

这是一个随机字符串，用于签名和验证 JWT Token。

#### 生成方法

**方法一：使用 Python 生成（推荐）**

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

**方法二：使用 OpenSSL 生成**

```bash
openssl rand -base64 32
```

**方法三：使用在线工具**

访问：https://www.random.org/strings/
- 长度：至少 32 字符
- 类型：字母数字混合

**方法四：手动生成**

使用任何随机字符串生成器，确保：
- 长度：至少 32 字符（推荐 64 字符）
- 复杂度：包含大小写字母、数字、特殊字符
- 安全性：不要使用可预测的字符串

**示例：**
```
JWT_SECRET=K8mN2pQ5rT9vW3xY7zA1bC4dE6fG8hJ0kL2mN4pQ6rT8vW0xY2zA4bC6dE8fG
```

## 📝 配置位置

### 配置文件：`oddsmind.env`

配置文件位置：`/home/ubuntu/oddsmind/oddsmind.env`

### 配置格式

```bash
# 微信小程序配置
WECHAT_APPID=wx1234567890abcdef
WECHAT_APPSECRET=your_app_secret_here_32_chars_minimum

# JWT Token 配置
JWT_SECRET=your_jwt_secret_key_at_least_32_chars_long_and_random

# 其他现有配置...
```

---

## 🔧 配置步骤

### 步骤一：编辑配置文件

```bash
cd /home/ubuntu/oddsmind
nano oddsmind.env
# 或
vim oddsmind.env
```

### 步骤二：添加配置

在文件末尾添加：

```bash
# 微信小程序配置
WECHAT_APPID=你的AppID
WECHAT_APPSECRET=你的AppSecret
JWT_SECRET=你的JWT密钥
```

### 步骤三：保存并重启服务

```bash
# 保存文件后
sudo systemctl restart oddsmind

# 检查服务状态
sudo systemctl status oddsmind
```

## ✅ 验证配置

### 方法一：检查环境变量

```bash
# 在应用启动后，检查日志
sudo journalctl -u oddsmind -n 50 | grep -i "wechat\|jwt"
```

### 方法二：测试接口

```bash
# 使用真实的微信 code 测试
curl -X POST http://localhost:8889/api/miniprogram/login \
  -H "Content-Type: application/json" \
  -d '{"code":"真实的微信code"}'
```

**如果配置正确：**
- 不会返回"未配置"错误
- 会尝试调用微信 API 获取 openid

**如果配置错误：**
- 返回"微信小程序 AppID 或 AppSecret 未配置"

## 🔒 安全建议

### 1. 保护 AppSecret

- ⚠️ **不要**将 AppSecret 提交到 Git
- ⚠️ **不要**在代码中硬编码
- ✅ 使用环境变量或配置文件
- ✅ 确保配置文件权限：`chmod 600 oddsmind.env`

### 2. 保护 JWT_SECRET

- ⚠️ **不要**使用弱密钥
- ✅ 使用强随机字符串（至少 32 字符）
- ✅ 定期更换（如果泄露）
- ✅ 不要共享给他人

### 3. 配置文件权限

```bash
# 设置配置文件权限（仅所有者可读写）
chmod 600 /home/ubuntu/oddsmind/oddsmind.env

# 检查权限
ls -l /home/ubuntu/oddsmind/oddsmind.env
```

## 🆘 常见问题

### Q1: 找不到 AppSecret？

**A:** 
- 如果未生成，点击"生成"按钮
- 如果已生成但忘记，需要重置（会失效旧的）

### Q2: 配置后仍然报错"未配置"？

**A:** 
- 检查配置文件格式（不要有多余空格）
- 检查环境变量是否正确加载
- 重启服务：`sudo systemctl restart oddsmind`

### Q3: 如何确认配置已生效？

**A:** 
```bash
# 查看应用日志
sudo journalctl -u oddsmind -f

# 测试接口（应该不会返回"未配置"错误）
curl -X POST http://localhost:8889/api/miniprogram/login \
  -H "Content-Type: application/json" \
  -d '{"code":"test"}'
```

### Q4: 小程序服务器域名配置在哪里？

**A:** 
- 微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名
- 需要添加：`https://oddsmind.top`
