# 定时任务服务修复说明

## 问题诊断

**问题现象**：广义实力表没有更新，最后一次更新是10月11日，之后就没有更新了。

**根本原因**：
1. 应用启动时，`auto_initialize()` 函数延迟10分钟执行初始化
2. 定时任务服务（`ScheduledDataUpdater`）在 `initialize_application()` 中启动
3. 由于延迟初始化，定时任务服务没有及时启动，导致每天凌晨01:59的广义实力计算任务没有执行

## 修复方案

### 1. 修改启动流程

修改了 `application/bootstrap.py` 中的 `auto_initialize()` 函数：

**修改前**：
- 所有服务都延迟10分钟启动

**修改后**：
- **定时任务服务立即启动**（不延迟）
- 其他服务延迟10分钟启动

### 2. 修复内容

在 `auto_initialize()` 函数中：
1. 添加了 `immediate_start_scheduler()` 函数，立即启动定时任务服务
2. 创建单独的线程立即启动定时任务服务
3. 其他服务仍然延迟10分钟启动

## 定时任务配置

定时任务服务配置在 `services/scheduled_data_updater.py`，包含以下任务：

| 任务ID | 执行时间 | 任务名称 | 描述 |
|--------|---------|---------|------|
| `daily_leagues_update` | 23:59 | 每日联赛数据更新 | 更新所有监控联赛的比赛数据 |
| `daily_odds_update` | 00:59 | 每日赔率数据更新 | 更新赔率数据（联赛更新后1小时） |
| `daily_strength_calculation` | **01:59** | **每日广义实力计算** | **计算广义实力（赔率更新后1小时）** |
| `daily_data_cleanup` | 03:00 | 每日数据清理 | 删除7天前的分析数据 |

## 下一步操作

### 1. 重启应用（应用修复）

需要重启正在运行的Flask应用，让修复生效：

```bash
# 查找应用进程
ps aux | grep "app.py" | grep -v grep

# 重启应用（根据你的部署方式）
# 如果使用systemd:
sudo systemctl restart oddsmind

# 或者手动重启:
# 1. 停止当前进程
kill <进程ID>

# 2. 重新启动
cd /home/ubuntu/oddsmind
source venv/bin/activate
python app.py
```

### 2. 验证定时任务服务

重启后，可以通过以下方式验证：

**方法1：使用检查脚本**
```bash
cd /home/ubuntu/oddsmind
source venv/bin/activate
python check_scheduler.py
```

**方法2：查看日志**
```bash
tail -f logs/oddsmind.log | grep -i "定时数据更新服务\|ScheduledDataUpdater"
```

应该看到类似以下日志：
```
立即启动定时任务服务...
定时数据更新服务已启动
定时任务配置完成
任务计划:
  23:59 - 联赛数据更新
  00:59 - 赔率数据更新
  01:59 - 广义实力计算
  03:00 - 数据清理（保留7天）
```

### 3. 手动执行一次广义实力计算（可选）

如果需要立即更新广义实力表，可以手动执行：

```bash
cd /home/ubuntu/oddsmind
source venv/bin/activate
python main.py calculate-strength --league-group monitored
```
