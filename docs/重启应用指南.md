# 重启应用指南

## ⚠️ 重要提示

**修改代码后必须重启应用才能生效！**

Python 应用在运行时会将代码加载到内存中，修改代码文件不会自动重新加载，需要重启应用。

---

## 🔄 重启方法

### 方法1: 使用 systemd 服务（推荐）

```bash
# 重启服务
sudo systemctl restart oddsmind

# 查看服务状态
sudo systemctl status oddsmind

# 查看启动日志
sudo journalctl -u oddsmind -n 50 -f
```

### 方法2: 手动重启

```bash
# 1. 查找进程
ps aux | grep "python.*app.py" | grep -v grep

# 2. 停止进程（使用 PID）
kill -9 <PID>

# 或使用 pkill
pkill -f "python.*app.py"

# 3. 重新启动
cd /home/ubuntu/oddsmind
source venv/bin/activate
python app.py
```

### 方法3: 使用启动脚本

```bash
cd /home/ubuntu/oddsmind
source venv/bin/activate
python start_with_port.py
```

## 🔍 检查应用是否正常运行

### 1. 检查进程

```bash
ps aux | grep python | grep app
```

### 2. 检查端口

```bash
netstat -tlnp | grep 8889
# 或
ss -tlnp | grep 8889
```

### 3. 测试接口

```bash
# 测试健康检查
curl http://localhost:8889/health

# 测试登录接口
curl -X POST http://localhost:8889/api/miniprogram/login \
  -H "Content-Type: application/json" \
  -d '{"code":"test"}'
```

### 4. 查看日志

```bash
# 实时查看日志
tail -f /home/ubuntu/oddsmind/logs/app.log

# 查看最近的错误
tail -n 100 /home/ubuntu/oddsmind/logs/app.log | grep -i error
```

## 🐛 常见问题

### 问题1: 端口被占用

**症状:** `Address already in use`

**解决:**
```bash
# 查找占用端口的进程
lsof -i :8889
# 或
netstat -tlnp | grep 8889

# 终止进程
kill -9 <PID>
```

### 问题2: 导入错误

**症状:** `ModuleNotFoundError` 或 `ImportError`

**解决:**
```bash
# 确保虚拟环境已激活
source venv/bin/activate

# 安装缺失的依赖
pip install -r requirements.txt

# 特别检查新添加的依赖
pip install PyJWT==2.8.0
```

### 问题3: 服务无法启动

**解决:**
```bash
# 查看详细错误信息
python app.py

# 或查看系统日志
journalctl -u oddsmind -n 100
```

## 💡 开发建议

### 开发环境使用自动重载

如果使用 Flask 开发模式，可以启用自动重载：

```python
if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8889, debug=True)
```

**注意:** 生产环境不要使用 `debug=True`！

### 使用 Gunicorn 或 uWSGI

生产环境建议使用 Gunicorn 或 uWSGI，它们支持更好的进程管理：

```bash
# 使用 Gunicorn
gunicorn -w 4 -b 0.0.0.0:8889 app:app

# 使用 uWSGI
uwsgi --http :8889 --wsgi-file app.py --callable app
```
