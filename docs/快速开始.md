# OddsMind 快速开始指南

## 🚀 两种部署方式快速开始

### 方式一：Git 仓库同步（5分钟）

```bash
# 1. 初始化 Git 仓库（首次）
cd /home/ubuntu/oddsmind
git init
git add .
git commit -m "Initial commit"

# 2. 添加远程仓库（GitHub/GitLab/Gitee）
git remote add origin https://github.com/yourusername/oddsmind.git
git branch -M main
git push -u origin main

# 3. 在其他服务器同步
git clone https://github.com/yourusername/oddsmind.git
cd oddsmind
./deploy-git.sh
```

### 方式二：Docker 一键部署（3分钟）

```bash
# 1. 构建并启动（包含 MySQL + Redis + 应用）
cd /home/ubuntu/oddsmind
./deploy-docker.sh

# 2. 查看服务状态
docker-compose ps

# 3. 查看日志
docker-compose logs -f oddsmind
```

## 📦 首次部署步骤

### Git 方式

1. **初始化仓库**
```bash
git init
git add .
git commit -m "Initial commit"
```

2. **创建远程仓库并推送**
```bash
# GitHub
git remote add origin https://github.com/yourusername/oddsmind.git
git push -u origin main

# 或 Gitee
git remote add origin https://gitee.com/yourusername/oddsmind.git
git push -u origin main
```

3. **配置环境变量**
```bash
cp oddsmind.env.example oddsmind.env  # 如果有示例文件
# 编辑 oddsmind.env，填入数据库、Redis 等配置
```

4. **安装依赖并启动**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

### Docker 方式

1. **配置环境变量**
```bash
# 创建 .env 文件或直接修改 docker-compose.yml 中的环境变量
cat > .env << EOF
DB_PASSWORD=your_secure_password
WECHAT_APPID=your_appid
WECHAT_APPSECRET=your_secret
WEB_ACCESS_PASSWORD=your_web_password
EOF
```

2. **一键启动**
```bash
./deploy-docker.sh
```

3. **访问应用**
```bash
# 应用地址
http://localhost:8889

# 健康检查
curl http://localhost:8889/health
```

## 🐳 Docker 镜像导出/导入

### 导出镜像到文件

```bash
# 构建镜像
docker build -t oddsmind:latest .

# 导出为 tar 文件
docker save -o oddsmind-latest.tar oddsmind:latest

# 压缩（可选）
gzip oddsmind-latest.tar
```

### 在其他服务器导入

```bash
# 导入镜像
docker load -i oddsmind-latest.tar

# 或从压缩文件
gunzip -c oddsmind-latest.tar.gz | docker load

# 使用导入的镜像
# 修改 docker-compose.yml，使用本地镜像
# 然后启动
docker-compose up -d
```

## ❓ 常见问题

### Q1: Git push 失败，提示权限错误

**解决：**
```bash
# 使用 SSH 密钥
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
# 将公钥添加到 GitHub/GitLab

# 或使用 Personal Access Token
git remote set-url origin https://token@github.com/username/repo.git
```

### Q2: Docker 构建失败

**解决：**
```bash
# 清理构建缓存
docker system prune -a

# 重新构建
docker-compose build --no-cache
```

### Q3: 数据库连接失败

**解决：**
```bash
# 检查环境变量
docker-compose exec oddsmind env | grep DB_

# 检查数据库服务
docker-compose ps mysql
docker-compose logs mysql
```

### Q4: 端口被占用

**解决：**
```bash
# 查看端口占用
netstat -tulpn | grep 8889

# 修改 docker-compose.yml 中的端口映射
# 例如：将 "8889:8889" 改为 "8890:8889"
```
