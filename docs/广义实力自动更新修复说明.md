# 广义实力自动更新修复说明

**修复日期**: 2025-12-28  
**问题**: 广义实力数据从12月8日之后就没有更新

---

## 🔍 问题分析

### 发现的问题

1. **调度任务时间错误**
   - 原配置：`01:59` 执行
   - 正确配置：`01:00` 执行（每天凌晨1点）

2. **Python路径错误**
   - 原配置：使用 `/home/ubuntu/oddsmind/venv/bin/python`
   - 问题：venv目录不存在，导致任务执行失败
   - 错误日志：
     ```
     2025-12-28 01:59:00,659 - ScheduledDataUpdater - ERROR - 广义实力计算任务执行失败: 
     [Errno 2] No such file or directory: '/home/ubuntu/oddsmind/venv/bin/python'
     ```

---

## ✅ 修复内容

### 1. 修改调度时间

**文件**: `services/scheduled_data_updater.py`

**修改前**:
```python
trigger=CronTrigger(hour=1, minute=59, timezone='Asia/Shanghai')
```

**修改后**:
```python
trigger=CronTrigger(hour=1, minute=0, timezone='Asia/Shanghai')
```

**说明**: 改为每天凌晨1点（01:00）执行。

---

### 2. 修复Python路径

**文件**: `services/scheduled_data_updater.py`

**修改前**:
```python
cmd = [
    os.path.join(self.project_root, 'venv', 'bin', 'python'),
    os.path.join(self.project_root, 'main.py'),
    'calculate-strength',
    ...
]
```

**修改后**:
```python
# [修复] 使用系统python3，而不是venv路径（venv可能不存在）
python_cmd = 'python3'  # 使用系统python3
venv_python = os.path.join(self.project_root, 'venv', 'bin', 'python')
if os.path.exists(venv_python):
    python_cmd = venv_python
else:
    self.logger.info(f"venv Python不存在 ({venv_python})，使用系统python3")

cmd = [
    python_cmd,
    os.path.join(self.project_root, 'main.py'),
    'calculate-strength',
    ...
]
```

**说明**: 
- 优先使用系统 `python3`
- 如果venv存在，则使用venv的python
- 避免路径不存在导致的错误
