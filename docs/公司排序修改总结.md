## 数据流

1. **数据库查询** (`get_odds_analyses`)
   - 查询 `odds_analysis_results` 表
   - 返回包含 `company_id` 字段的数据

2. **排序** (`sort_analyses_by_priority`)
   - 使用 `PERSONAL_COMPANY_ORDER` 排序
   - 按 `company_id` 在 `PERSONAL_COMPANY_ORDER` 中的位置排序

3. **格式化** (`format_analysis_data`)
   - 将 `company_id` 转换为 `companyId`
   - 返回给前端

4. **前端显示**
   - 直接使用后端返回的 `companyAnalyses` 数组顺序
   - 生成下拉框选项

## 重要：必须重启服务

**所有修改都需要重启Flask服务才能生效！**

```bash
# 重启服务
sudo systemctl restart oddsmind

# 或手动重启
pkill -f "python.*app.py"
cd /home/ubuntu/oddsmind
source venv/bin/activate
python app.py
```

## 验证方法

重启服务后：
1. 清除浏览器缓存（Ctrl+F5）
2. 访问比赛详情页
3. 检查公司下拉框顺序：
   - 前5个应该是：马会 → 澳门 → 威廉 → 平博 → Interwetten
   - 后面是其他公司
4. 查看服务器日志，确认排序日志输出

## 如果仍然不生效

1. **确认服务已重启**：检查进程是否重新启动
2. **检查日志**：查看是否有排序相关的日志输出
3. **检查浏览器控制台**：查看API返回的 `companyAnalyses` 数组顺序
4. **检查数据库**：确认 `odds_analysis_results` 表中有这些公司的数据
