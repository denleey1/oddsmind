# 时区配置说明

## 概述

项目已配置统一的时区处理机制，默认使用 **Asia/Shanghai (UTC+8)** 时区。所有时区相关的配置都集中在配置文件中，确保代码中明确指定时区。

## 配置位置

### 1. 核心配置 (`core/config.py`)

时区配置类 `TimezoneConfig` 包含以下字段：

- `timezone_name`: 时区名称，默认 `"Asia/Shanghai"`
- `mysql_timezone_offset`: MySQL时区偏移，默认 `"+08:00"`
- `use_timezone_aware`: 是否使用时区感知的datetime，默认 `True`

### 2. 设置文件 (`config/settings.py`)

时区设置类 `TimezoneSettings` 从核心配置中加载，并提供向后兼容的接口。

## 环境变量

可以通过以下环境变量覆盖默认配置：

```bash
# 设置时区名称（例如：Asia/Shanghai, UTC, America/New_York）
export TIMEZONE="Asia/Shanghai"

# 设置MySQL时区偏移（例如：+08:00, +00:00, -05:00）
export MYSQL_TIMEZONE_OFFSET="+08:00"

# 是否使用时区感知的datetime（true/false）
export USE_TIMEZONE_AWARE="true"
```

## 使用方式

### 1. 时区工具模块 (`utils/timezone_utils.py`)

推荐使用时区工具模块提供的函数，而不是直接使用 `datetime.now()`：

```python
from utils.timezone_utils import now, now_utc, to_timezone_aware, to_utc, to_local

# 获取当前时间（时区感知，使用配置的时区）
current_time = now()  # 返回 Asia/Shanghai 时区的datetime对象

# 获取当前UTC时间
utc_time = now_utc()

# 转换datetime为时区感知对象
aware_dt = to_timezone_aware(naive_dt)

# 转换为UTC时间
utc_dt = to_utc(dt)

# 转换为本地时区时间
local_dt = to_local(dt)
```

### 2. 数据库连接

数据库连接会自动使用配置的时区。在 `app_database.py` 中，每次数据库操作都会设置会话时区：

```python
# 自动使用配置的时区偏移（默认：+08:00）
cursor.execute(f"SET time_zone = '{get_mysql_timezone_offset()}'")
```

### 3. 定时任务

定时任务调度器已配置时区：

```python
# services/scheduled_data_updater.py
self.scheduler = BackgroundScheduler(timezone='Asia/Shanghai')
```

所有 `CronTrigger` 也明确指定了时区：

```python
trigger=CronTrigger(hour=23, minute=59, timezone='Asia/Shanghai')
```

## 最佳实践

### ✅ 推荐做法

1. **使用时区工具模块**：
   ```python
   from utils.timezone_utils import now, to_timezone_aware
   current_time = now()  # 时区感知
   ```

2. **存储UTC时间到数据库**（如果跨时区部署）：
   ```python
   from utils.timezone_utils import now_utc
   utc_time = now_utc()
   ```

3. **显示时转换为本地时区**：
   ```python
   from utils.timezone_utils import to_local
   local_dt = to_local(utc_dt)
   ```

### ❌ 不推荐做法

1. **直接使用 `datetime.now()`**（无时区信息）：
   ```python
   # 不推荐
   dt = datetime.now()  # 无时区信息
   ```

2. **假设系统时区**：
   ```python
   # 不推荐
   import time
   tz_offset = time.strftime('%z')  # 依赖系统时区
   ```

## 迁移指南

如果现有代码使用了 `datetime.now()`，建议逐步迁移到时区工具模块：

### 步骤1：导入时区工具
```python
from utils.timezone_utils import now as get_now
```

### 步骤2：替换 `datetime.now()`
```python
# 旧代码
from datetime import datetime
current_time = datetime.now()

# 新代码
from utils.timezone_utils import now
current_time = now()  # 时区感知
```

### 步骤3：处理时区转换
如果代码需要与数据库交互，确保使用正确的时区：

```python
# 如果数据库存储的是本地时区时间
from utils.timezone_utils import now, to_timezone_aware
db_time = to_timezone_aware(naive_dt)

# 如果数据库存储的是UTC时间
from utils.timezone_utils import now_utc
db_time = now_utc()
```

## 注意事项

1. **数据库时区设置**：确保MySQL服务器的时区设置与应用配置一致。

2. **跨时区部署**：如果应用需要跨时区部署，建议：
   - 数据库存储UTC时间
   - 应用层转换为本地时区显示

3. **夏令时**：使用 `pytz` 时区对象可以正确处理夏令时（DST）变化。

4. **向后兼容**：现有的 `datetime.now()` 代码仍然可以工作，但建议逐步迁移到时区工具模块。

## 验证时区配置

可以运行以下代码验证时区配置是否正确：

```python
from utils.timezone_utils import get_timezone_info, now, now_utc
from datetime import datetime

# 显示时区信息
info = get_timezone_info()
print("时区配置信息：")
for key, value in info.items():
    print(f"  {key}: {value}")

# 对比时间
print("\n时间对比：")
print(f"  配置时区当前时间: {now()}")
print(f"  UTC当前时间: {now_utc()}")
print(f"  系统本地时间（无时区）: {datetime.now()}")
```

## 故障排查

如果遇到时区相关问题：

1. **检查配置**：
   ```python
   from config.settings import settings
   print(f"时区名称: {settings.timezone.timezone_name}")
   print(f"MySQL偏移: {settings.timezone.mysql_timezone_offset}")
   ```

2. **检查数据库时区**：
   ```sql
   SELECT @@global.time_zone, @@session.time_zone;
   SELECT NOW(), UTC_TIMESTAMP();
   ```

3. **检查系统时区**：
   ```bash
   timedatectl  # Linux
   date  # 显示当前系统时间
   ```
