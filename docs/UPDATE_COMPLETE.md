#### 4. 信心中庸双值机制

**核心逻辑：**
```javascript
当双方都是"信心中庸"时：
  if (我方分数 < 对手分数) {
    使用 lower 值  // 弱势方
  } else if (我方分数 > 对手分数) {
    使用 higher 值 // 优势方
  } else {
    使用 lower 值  // 平局默认
  }

当对手不是"信心中庸"时：
  使用 lower 值  // 默认值
```

**示例：**
- 主队：信心中庸(5.0分) vs 客队：信心中庸(5.2分)
  - 主队受注力使用 `lower` 值（5.0 < 5.2）
  - 客队受注力使用 `higher` 值（5.2 > 5.0）

- 主队：信心中庸(5.0分) vs 客队：信心充足(8.0分)
  - 主队受注力使用 `lower` 值（对手不是中庸）
  - 客队正常使用"信心充足"的固定值
