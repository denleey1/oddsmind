# 理论区间功能实现说明

## 功能概述
在赔率分析表格的右边，选择公司旁边增加了一个"理论区间"按钮。点击后，根据API传的主客队的广义实力描述，输出理论开盘区间、理论让球以及胜平负的赔率。

## 功能特点

### 1. 公司到体系的自动映射
根据选择的公司名称自动选择对应的标准体系：
- 威廉公司 → 威廉93.5
- 澳门公司 → 澳门90.2
- 马会公司 → 马会88.2
- 竞彩公司 → 竞彩88.6
- 其他公司 → 标准89

### 2. 美观的弹窗展示
- 渐变背景（紫色系）
- 半透明遮罩层
- 响应式布局
- 流畅的动画效果
- 可点击遮罩层关闭

### 3. 详细的信息展示
对于每个匹配的区间，显示：
- 主队/客队让球区间
- 区间标签（如"1区 (平手-0)"）
- 主胜赔率范围（绿色）
- 平局赔率范围（黄色）
- 客胜赔率范围（红色）
- 返还率范围（蓝色）

### 4. 错误处理
- 检查是否有当前比赛数据
- 检查是否有公司选择器
- 检查是否有广义实力数据
- 等待模块加载完成
- 友好的错误提示

## 使用方法

1. 打开比赛详情页面
2. 在赔率分析表格的右上角，选择公司旁边可以看到"📊 理论区间"按钮
3. 点击按钮后，系统会：
   - 获取当前选择的公司
   - 获取主客队的广义实力
   - 自动匹配到对应的体系
   - 显示理论开盘区间和赔率范围
4. 点击弹窗外部或关闭按钮可关闭弹窗

## 注意事项

1. **不影响现有功能**：所有修改都是新增功能，没有修改任何现有代码逻辑
2. **模块加载**：`frontend_odds_lookup.js`作为ES6模块加载，并暴露到全局`window.OddsLookup`对象
3. **体系映射**：通过公司名称的关键词匹配自动选择体系，不区分大小写
4. **数据要求**：需要公司数据有`homeTierLevel`和`awayTierLevel`字段（广义实力文字描述）

## 修复记录

### 2024-11-12 修复广义实力获取问题
**问题描述**：
初始版本从`window.currentMatchData.analysis`对象获取广义实力，但该字段不存在，导致提示"缺少主队广义实力"。

**解决方案**：
从当前选择的公司对象中获取广义实力：
```javascript
const company = window.allCompanyAnalyses.find(c => c.companyId == selectedCompanyId);
const homeGeneralStrength = company.homeTierLevel || '';
const awayGeneralStrength = company.awayTierLevel || '';
```

这与表格"即时盘"行中显示的广义实力数据来源一致。

## 技术实现

### 数据流
```
用户点击按钮
    ↓
获取当前公司和广义实力
    ↓
映射到标准体系
    ↓
调用window.OddsLookup.lookupOdds()
    ↓
从zoneMap查找匹配的区间
    ↓
从standardOdds获取赔率数据
    ↓
格式化并显示结果
```

### 关键数据结构
- `zoneMap`: 广义实力到区间的映射
- `standardOdds`: 各体系的标准赔率表
- 支持的体系：标准89、澳门90.2、竞彩88.6、马会88.2、威廉94.5、威廉93.5
