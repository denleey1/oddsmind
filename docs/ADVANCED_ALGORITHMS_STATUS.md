## 📝 技术细节

### 双变量泊松实现
```python
# 主客队进球非独立，共享成分λ3
X = U + A  # 主队 = 共享 + 独立
Y = U + B  # 客队 = 共享 + 独立
# λ3自动从平局概率估计
```

### Dixon-Coles修正因子
```python
τ(0,0) = 1 - λh·λa·ρ
τ(1,0) = 1 + λa·ρ
τ(0,1) = 1 + λh·ρ  
τ(1,1) = 1 - ρ
# ρ≈-0.13 (联赛自动估计)
```

### 负二项参数
```python
# 从2.5和3.5盘联合拟合
P(S≥3) = 1 - F_NB(2; μ, k)
P(S≥4) = 1 - F_NB(3; μ, k)
# 同时满足两个约束
```
