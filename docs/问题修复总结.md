### 问题2: require_json 装饰器使用错误
**错误信息:**
```
TypeError: require_json() missing 1 required positional argument: 'schema'
```

**原因:**
`require_json` 不是装饰器，而是一个函数，需要在函数内部调用。

**修复:**
- 移除了 `@require_json` 装饰器
- 在函数内部调用 `require_json(request, schema)`
- 添加了 `JsonValidationError` 异常处理

**修改文件:**
- `application/routes/miniprogram.py`
