## 📋 接口列表

### 1. 微信登录接口

**接口路径:** `POST /api/miniprogram/login`

**完整URL:**
- 生产: `https://oddsmind.top/api/miniprogram/login`
- 本地: `http://localhost:8889/api/miniprogram/login`

**请求头:**
```
Content-Type: application/json
```

**请求体:**
```json
{
    "code": "wx.login()获取的code"
}
```

**成功响应（未激活）:**
```json
{
    "success": true,
    "data": {
        "openid": "oXXXXXXXXXXXXX",
        "is_activated": false,
        "message": "需要激活账号"
    }
}
```

**成功响应（已激活）:**
```json
{
    "success": true,
    "data": {
        "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "user": {
            "id": 123,
            "openid": "oXXXXXXXXXXXXX",
            "nickname": "用户昵称",
            "avatar_url": "https://...",
            "is_activated": true,
            "expires_at": "2024-12-31T23:59:59"
        }
    }
}
```

**错误响应:**
```json
{
    "success": false,
    "error": "错误信息"
}
```

**状态码:**
- `200` - 成功
- `400` - 请求参数错误
- `500` - 服务器错误

### 2. 激活账号接口（验证邀请码）

**接口路径:** `POST /api/miniprogram/activate`

**完整URL:**
- 生产: `https://oddsmind.top/api/miniprogram/activate`
- 本地: `http://localhost:8889/api/miniprogram/activate`

**请求头:**
```
Content-Type: application/json
```

**请求体:**
```json
{
    "code": "wx.login()获取的code",
    "invite_code": "INVITE123"
}
```

**成功响应:**
```json
{
    "success": true,
    "data": {
        "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "user": {
            "id": 123,
            "openid": "oXXXXXXXXXXXXX",
            "nickname": "用户昵称",
            "avatar_url": "https://...",
            "is_activated": true,
            "expires_at": "2024-12-31T23:59:59"
        }
    }
}
```

**错误响应:**
```json
{
    "success": false,
    "error": "邀请码无效或已过期"
}
```

**状态码:**
- `200` - 成功
- `400` - 请求参数错误或邀请码无效
- `500` - 服务器错误

### 3. 获取用户信息接口

**接口路径:** `GET /api/miniprogram/user`

**完整URL:**
- 生产: `https://oddsmind.top/api/miniprogram/user`
- 本地: `http://localhost:8889/api/miniprogram/user`

**请求头:**
```
Authorization: Bearer <jwt_token>
Content-Type: application/json
```

**请求体:** 无

**成功响应:**
```json
{
    "success": true,
    "data": {
        "id": 123,
        "openid": "oXXXXXXXXXXXXX",
        "nickname": "用户昵称",
        "avatar_url": "https://...",
        "is_activated": true,
        "expires_at": "2024-12-31T23:59:59",
        "last_login_at": "2024-01-01T12:00:00"
    }
}
```

**错误响应:**
```json
{
    "success": false,
    "error": "未登录或登录已过期"
}
```

**状态码:**
- `200` - 成功
- `401` - 未授权（Token无效或过期）
- `404` - 用户不存在
- `500` - 服务器错误

## 🔄 完整流程示例

### 1. 用户首次登录（未激活）

```javascript
// 步骤1: 调用微信登录
wx.login({
  success: (res) => {
    const code = res.code
    
    // 步骤2: 调用后端登录接口
    wx.request({
      url: 'https://oddsmind.top/api/miniprogram/login',
      method: 'POST',
      data: { code },
      success: (res) => {
        if (res.data.success) {
          if (!res.data.data.is_activated) {
            // 步骤3: 显示邀请码输入界面
            // 用户输入邀请码后调用激活接口
          } else {
            // 已激活，保存 Token
            wx.setStorageSync('token', res.data.data.token)
          }
        }
      }
    })
  }
})
```

### 2. 激活账号

```javascript
// 用户输入邀请码后
wx.login({
  success: (res) => {
    const code = res.code
    
    wx.request({
      url: 'https://oddsmind.top/api/miniprogram/activate',
      method: 'POST',
      data: {
        code: code,
        invite_code: 'INVITE123'
      },
      success: (res) => {
        if (res.data.success) {
          // 保存 Token 和用户信息
          wx.setStorageSync('token', res.data.data.token)
          wx.setStorageSync('userInfo', res.data.data.user)
          // 跳转到首页
        }
      }
    })
  }
})
```

### 3. 获取用户信息（已登录）

```javascript
const token = wx.getStorageSync('token')

wx.request({
  url: 'https://oddsmind.top/api/miniprogram/user',
  method: 'GET',
  header: {
    'Authorization': `Bearer ${token}`
  },
  success: (res) => {
    if (res.data.success) {
      console.log('用户信息:', res.data.data)
    } else if (res.statusCode === 401) {
      // Token 过期，跳转到登录页
      wx.reLaunch({
        url: '/pages/login/login'
      })
    }
  }
})
```

---

## ⚠️ 注意事项

1. **Token 存储**: 建议使用 `wx.setStorageSync` 存储 Token
2. **Token 过期**: Token 有效期为 7 天，过期后需要重新登录
3. **账号过期**: 账号过期时间由邀请码决定，过期后无法使用
4. **错误处理**: 所有接口调用都应该有错误处理
5. **401 处理**: 收到 401 响应时，应该清除本地 Token 并跳转到登录页
