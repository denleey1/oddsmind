# 公司排序配置修改方案

## 一、配置位置

### 1. 主要排序配置
**文件**：`app_constants.py`
**变量**：`PERSONAL_COMPANY_ORDER`
**当前值**：`[432, 80, 115, 517, 791, 2, 177, 281, 255, 708]`
**用途**：控制公司优先级排序，用于 `app_services.py` 中的排序逻辑

### 2. AI分析服务中的公司配置
**文件**：`application/services/match_analysis_service.py`
**变量**：`COMPANY_IDS` 字典
**当前顺序**：
```python
COMPANY_IDS = {
    '马会': 432,      # HKJC
    '澳门': 80,       # Macau
    '威廉': 115,      # William Hill

```
**用途**：AI分析时使用的5家公司，按字典顺序排序

### 3. 前端显示
**文件**：`static/js/app_modern.js`
**逻辑**：
- 初始显示前10个公司（`initialLoadCount = 10`）
- 点击"加载全部"显示所有公司
- 下拉框按照后端返回的数组顺序生成

## 三、需要修改的地方

### 修改1：`app_constants.py` - PERSONAL_COMPANY_ORDER

**当前**：
```python
PERSONAL_COMPANY_ORDER = [432, 80, 115, 517, 791, 2, 177, 281, 255, 708]
```

**修改为**：
```python
# 公司优先级排序 (按重要性排序)
# 前5个是核心公司：马会、澳门、威廉、平博、Interwetten
# 432-香港马会, 80-澳门, 115-威廉希尔, 281-平博, 190-Interwetten
# 其他公司：517-明陞, 791-Sisasal, 2-Betfair英国, 177-Pinnacle(旧), 255-bwin, 708-Unibet
PERSONAL_COMPANY_ORDER = [432, 80, 115, 281, 190, 517, 791, 2, 177, 255, 708]
```

**说明**：
- 前5个：马会(432)、澳门(80)、威廉(115)、平博(281)、Interwetten(190)
- 后面保持原有其他公司的顺序

### 修改2：`application/services/match_analysis_service.py` - COMPANY_IDS 字典顺序

**当前**：
```python
COMPANY_IDS = {
    '马会': 432,      # HKJC
    '澳门': 80,       # Macau
    '威廉': 115,      # William Hill
    '平博': 281,      # Pinnacle
    'Interwetten': 190  # Interwetten (塞浦路斯)
}
```

**修改为**：
```python
COMPANY_IDS = {
    '马会': 432,      # HKJC
    '澳门': 80,       # Macau
    '威廉': 115,      # William Hill
    '平博': 281,      # Pinnacle
    'Interwetten': 190  # Interwetten (塞浦路斯)
}
```

**说明**：
- 字典顺序已经是正确的（马会、澳门、威廉、平博、Interwetten）
- 但排序逻辑使用的是 `list(COMPANY_IDS.values())`，所以顺序已经正确
- 只需要确认排序逻辑正确即可

### 修改3：检查排序逻辑

**文件**：`application/services/match_analysis_service.py` 第203-204行

**当前代码**：
```python
# 按公司顺序排序（马会、威廉、澳门、Interwetten、平博）
result.sort(key=lambda x: list(COMPANY_IDS.values()).index(int(x['companyId'])))
```

**问题**：
- 注释说的是"马会、威廉、澳门、Interwetten、平博"
- 但实际顺序应该是"马会、澳门、威廉、平博、Interwetten"
- 需要更新注释

**修改为**：
```python
# 按公司顺序排序（马会、澳门、威廉、平博、Interwetten）
# 使用COMPANY_IDS字典的值顺序进行排序
result.sort(key=lambda x: list(COMPANY_IDS.values()).index(int(x['companyId'])) if int(x['companyId']) in COMPANY_IDS.values() else 999)
```

**说明**：
- 更新注释为正确顺序
- 添加异常处理：如果公司ID不在COMPANY_IDS中，排到最后（999）
