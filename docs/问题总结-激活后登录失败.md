# 问题总结：激活后登录失败

## 🔍 问题现象

1. ✅ 激活成功，token和用户信息都已保存
2. ✅ 激活后验证：Token已保存，用户信息已保存，is_activated: true
3. ❌ 重新登录时返回：`{success: false, needActivate: true, openid: undefined}`

## 🐛 问题根源

**这是前端问题，不是后端问题！**

### 原因分析

1. **后端日志显示登录成功**：
   - `登录检查: is_activated=1` ✅
   - `登录成功` ✅

2. **前端收到 `needActivate: true`**：
   - 说明前端收到的响应中 `data.is_activated` 为 `false` 或 `undefined`
   - `openid: undefined` 说明 `data.openid` 不存在

3. **可能的原因**：
   - 重新登录时使用的code可能已过期
   - 重新登录时获取到了不同的openid（不太可能）
   - 前端代码逻辑问题

## ✅ 解决方案

### 方案1: 激活成功后不重新登录（推荐）⭐

**原因：**
- 激活接口已经返回了token和用户信息
- 数据已经保存到本地存储
- 不需要重新登录

**修改 `pages/login/login.js`：**

```javascript
async onSubmitActivate() {
  const inviteCode = this.data.inviteCode.trim()

  if (!inviteCode) {
    wx.showToast({
      title: '请输入邀请码',
      icon: 'none'
    })
    return
  }

  this.setData({ loading: true, errorMessage: '' })

  try {
    const result = await auth.activate(inviteCode)

    if (result.success) {
      // ✅ 验证数据是否已保存
      const token = auth.getToken()
      const userInfo = auth.getUserInfoSync()

      if (!token || !userInfo || !userInfo.is_activated) {
        // 数据未保存或未激活，重新登录
        setTimeout(() => {
          this.autoLogin()
        }, 1000)
        return
      }

      wx.showToast({
        title: '激活成功',
        icon: 'success'
      })
      
      // ✅ 激活成功，直接跳转（不需要重新登录）
      setTimeout(() => {
        this.redirectToHome()
      }, 1500)
    } else {
      this.setData({
        loading: false,
        errorMessage: result.error || '激活失败，请检查邀请码'
      })
      wx.showToast({
        title: result.error || '激活失败',
        icon: 'none'
      })
    }
  } catch (error) {
    console.error('激活异常:', error)
    this.setData({
      loading: false,
      errorMessage: error.message || '激活失败，请稍后重试'
    })
    wx.showToast({
      title: '激活失败',
      icon: 'none'
    })
  }
}
```

### 方案2: 如果必须重新登录，确保使用新的code

如果确实需要重新登录，确保每次调用 `wx.login()` 获取新的code：

```javascript
// 在 auth.js 的 login() 方法中，确保每次都获取新的code
async login() {
  try {
    // ✅ 每次都获取新的code
    const loginRes = await this.wxLogin()
    const code = loginRes.code
    
    if (!code) {
      throw new Error('无法获取微信登录code')
    }

    const response = await api.post('/miniprogram/login', { code })

    if (!response.success) {
      throw new Error(response.error || '登录失败')
    }

    const data = response.data

    // ✅ 检查响应数据
    if (!data) {
      throw new Error('登录接口返回数据为空')
    }

    // ✅ 如果未激活，返回需要激活的状态
    if (data.is_activated === false || !data.is_activated) {
      return {
        success: false,
        needActivate: true,
        openid: data.openid,
        message: data.message || '需要激活账号'
      }
    }

    // ✅ 已激活，保存 Token 和用户信息
    if (data.token) {
      storage.set(TOKEN_KEY, data.token)
    }
    if (data.user) {
      storage.set(USER_INFO_KEY, data.user)
    }

    return {
      success: true,
      user: data.user,
      token: data.token
    }
  } catch (error) {
    console.error('登录失败:', error)
    return {
      success: false,
      error: error.message || '登录失败，请稍后重试'
    }
  }
}
```

## 🎯 推荐方案

**强烈推荐使用方案1**：激活成功后直接跳转，不需要重新登录。

**优势：**
1. ✅ 避免code过期问题
2. ✅ 减少网络请求
3. ✅ 用户体验更好
4. ✅ 逻辑更简单
