### 1.2 定时任务执行计划

根据 `ScheduledDataUpdater` 类的配置，系统设置了3个定时任务：

| 任务ID | 执行时间 | 任务名称 | 函数 | 描述 |

| `daily_leagues_update` | **23:59** | 每日联赛数据更新 | `_update_leagues_task()` | 更新所有监控联赛的比赛数据 |
| `daily_odds_update` | **00:59** | 每日赔率数据更新 | `_update_odds_task()` | 更新赔率数据（联赛更新后1小时） |
| `daily_strength_calculation` | **01:59** | 每日广义实力计算 | `_calculate_strength_task()` | 计算广义实力（赔率更新后1小时） |

### 1.3 广义实力计算任务详情

**任务配置** (第84-92行):
```python
# 任务3: 每日01:59计算广义实力 (赔率更新后1小时)
self.scheduler.add_job(
    func=self._calculate_strength_task,
    trigger=CronTrigger(hour=1, minute=59),
    id='daily_strength_calculation',
    name='每日广义实力计算',
    max_instances=1,
    coalesce=True
)
```

**执行命令** (第330-335行):

## 四、定时任务启动机制

### 4.1 启动流程

根据 `/home/ubuntu/oddsmind/application/bootstrap.py`:

1. **应用初始化时** (`init_scheduler()` 函数):
   ```python
   scheduler.add_job(
       start_scheduled_data_updater,
       'date',
       run_date=datetime.now(),
       id='scheduled_data_updater_start',
       replace_existing=True,
   )
   ```

2. **创建定时任务实例**:
   ```python
   updater = get_scheduled_updater(runtime=_runtime)
   updater.start()
   _runtime.scheduled_data_updater = updater
   ```

3. **后台调度器启动**:
   - 使用 `BackgroundScheduler` (时区: Asia/Shanghai)
   - 自动注册3个定时任务 (23:59, 00:59, 01:59)

### 4.2 API接口

系统提供API接口查看和管理定时任务:

**查看状态**:
```
GET /api/v1/scheduler/status
```

**手动执行任务**:
```
POST /api/v1/scheduler/tasks/run
Body: {"task_name": "strength_calculation"}
```
