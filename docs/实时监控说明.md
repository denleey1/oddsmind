### 2. 联赛状态监控优化
**监控内容**:

- ✅ 并发数日志：`并发数.*10`

**检查命令**:


### 3. 404错误快速失败
**监控内容**:
- ⏳ 404错误出现时，应该看到：
  - `fast_fail: True`
  - `cached invalid`
  - `marking as invalid and skipping retry`
- ⏳ 不应该看到：404错误重试3次

**检查命令**:
```bash
grep -E "404.*fast_fail|404.*cached|404.*marking" logs/oddsmind.log | tail -10
```

### 4. 速率限制重试
**监控内容**:
- ✅ 应该看到：`Rate limit timeout.*retrying`
- ❌ 不应该看到：`Rate limit timeout.*skipping`（直接跳过）

**检查命令**:
```bash
grep "Rate limit.*retrying" logs/oddsmind.log | tail -10
```

### 5. 无效ID缓存
**监控内容**:
- ⏳ 404错误后，再次请求相同ID应该看到：
  - `is in invalid cache, skipping`
  - `cached invalid`

**检查命令**:
```bash
grep -E "invalid cache|cached invalid" logs/oddsmind.log | tail -10
```
