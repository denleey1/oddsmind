# 后端 API 错误响应格式完整文档

## 📋 标准响应格式

### ✅ 成功响应
```json
{
  "success": true,
  "message": "OK",
  "data": {
    // 具体数据
  }
}
```

### ❌ 错误响应
```json
{
  "success": false,
  "message": "具体错误信息"
}
```

**注意：** 后端使用 `message` 字段，不是 `error` 字段！

## 🔐 激活接口 `/api/miniprogram/activate`

### 请求格式
```json
POST /api/miniprogram/activate
Content-Type: application/json

{
  "code": "微信登录code",
  "invite_code": "激活码"
}
```

### 成功响应 (200)
```json
{
  "success": true,
  "message": "OK",
  "data": {
    "token": "jwt_token_here",
    "user": {
      "id": 123,
      "openid": "xxx",
      "nickname": null,
      "avatar_url": null,
      "is_activated": true,
      "expires_at": "2025-11-17T12:45:16"
    }
  }
}
```

### 错误响应（所有可能的情况）

#### 1️⃣ 参数缺失 (400)
```json
{
  "success": false,
  "message": "请求缺少字段 'code'"
}
```
或
```json
{
  "success": false,
  "message": "请求缺少字段 'invite_code'"
}
```

**原因：** 请求中没有提供 `code` 或 `invite_code`

---

#### 2️⃣ 请求格式错误 (400)
```json
{
  "success": false,
  "message": "请求缺少有效的 JSON 数据"
}
```

**原因：** Content-Type 不是 application/json 或 body 不是有效 JSON

---

#### 3️⃣ 微信 code 重复使用 (400)
```json
{
  "success": false,
  "message": "登录凭证已失效，请重新登录"
}
```

**原因：** 同一个微信 code 被使用了两次（防重放攻击）

**解决方法：** 重新调用 `wx.login()` 获取新的 code

---

#### 4️⃣ 微信 API 调用失败 (400)
```json
{
  "success": false,
  "message": "微信登录失败: invalid code (错误码: 40029)"
}
```

**常见原因：**
- code 已过期（5分钟有效期）
- code 格式错误
- 网络问题

**解决方法：** 重新调用 `wx.login()` 获取新的 code

---

#### 5️⃣ 无法获取 openid (400)
```json
{
  "success": false,
  "message": "无法获取 openid"
}
```

**原因：** 微信 API 返回的数据中没有 openid（极少发生）

---

#### 6️⃣ 用户已激活 (400)
```json
{
  "success": false,
  "message": "账号已激活，请直接登录"
}
```

**原因：** 该用户已经激活过，不能重复激活

**解决方法：** 引导用户直接登录（调用 `/api/miniprogram/login`）

---

#### 7️⃣ 激活码无效或已失效 (400) ⭐ 最常见
```json
{
  "success": false,
  "message": "激活码无效或已失效"
}
```

**可能的原因（后端不会详细告知，防止枚举攻击）：**
- ❌ 激活码不存在
- ❌ 激活码已被禁用
- ❌ 激活码使用次数已达上限
- ❌ 激活码已过期
- ❌ 激活码格式错误

**解决方法：** 
1. 检查激活码是否输入正确
2. 联系管理员确认激活码状态

---

#### 8️⃣ 服务器内部错误 (500)
```json
{
  "success": false,
  "message": "激活失败，请稍后重试"
}
```

**原因：** 数据库连接失败、代码异常等

**解决方法：** 稍后重试，或联系技术支持

---

#### 9️⃣ Rate Limiting (429) ⭐ 新增
```json
{
  "success": false,
  "error": "请求过于频繁，请在 45 秒后重试",
  "rate_limit": {
    "limit": 5,
    "remaining": 0,
    "reset": 1700123456,
    "retry_after": 45
  }
}
```

**原因：** 每分钟最多 5 次激活请求

**解决方法：** 等待 `retry_after` 秒后重试

**响应头：**
```
X-RateLimit-Limit: 5
X-RateLimit-Remaining: 0
X-RateLimit-Reset: 1700123456
```

## ⚠️ 重要：401 错误处理（账号过期/用户被删除）

### 后端行为

**每次API请求都会检查：**
1. ✅ 用户是否存在于数据库
2. ✅ 用户是否仍然激活
3. ✅ 账号是否过期

**如果检查失败，返回 401：**
```json
{
  "success": false,
  "error": "账号已过期"
}
```
或
```json
{
  "success": false,
  "error": "用户不存在，请重新登录"
}
```

### 前端处理建议

**必须实现全局 401 错误拦截：**

```javascript
// utils/api.js 或 app.js
// 全局请求拦截器
wx.request({
  // ... 请求配置
  success: function(res) {
    // 正常处理
  },
  fail: function(err) {
    // 网络错误处理
  },
  complete: function(res) {
    // 检查 401 错误
    if (res.statusCode === 401) {
      const errorMsg = res.data?.error || res.data?.message || '登录已过期';
      
      // 清除本地存储
      wx.removeStorageSync('token');
      wx.removeStorageSync('user');
      
      // 显示提示
      wx.showModal({
        title: '登录已过期',
        content: errorMsg,
        showCancel: false,
        confirmText: '重新登录',
        success: function() {
          // 跳转到登录页
          wx.reLaunch({
            url: '/pages/login/login'
          });
        }
      });
    }
  }
});
```

**或者使用 Promise 封装：**

```javascript
// utils/request.js
function request(options) {
  return new Promise((resolve, reject) => {
    wx.request({
      ...options,
      header: {
        'Authorization': `Bearer ${wx.getStorageSync('token')}`,
        ...options.header
      },
      success: (res) => {
        // 检查 401
        if (res.statusCode === 401) {
          handle401Error(res.data);
          reject(new Error(res.data?.error || '登录已过期'));
          return;
        }
        resolve(res.data);
      },
      fail: reject
    });
  });
}

function handle401Error(data) {
  const errorMsg = data?.error || data?.message || '登录已过期';
  
  // 清除本地存储
  wx.removeStorageSync('token');
  wx.removeStorageSync('user');
  
  // 显示提示并跳转
  wx.showModal({
    title: '登录已过期',
    content: errorMsg,
    showCancel: false,
    confirmText: '重新登录',
    success: () => {
      wx.reLaunch({
        url: '/pages/login/login'
      });
    }
  });
}
```

### 触发场景

以下情况会立即返回 401：

1. **账号过期**
   - 用户账号的 `expires_at` < 当前时间
   - 每次API请求都会检查
   - **立即生效，无需等待Token过期**

2. **用户被删除**
   - 管理员清理用户后
   - 下次API请求立即返回 401
   - **立即生效**

3. **用户被禁用**
   - `is_activated = 0`
   - 下次API请求立即返回 401
   - **立即生效**

4. **Token过期**
   - JWT Token本身的 `exp` 过期
   - 返回 401

## 📱 前端处理建议

### 1. 统一错误处理函数

```javascript
// utils/api.js
function handleApiError(error, defaultMessage = '操作失败') {
  if (!error.response) {
    // 网络错误
    return '网络连接失败，请检查网络';
  }
  
  const { status, data } = error.response;
  
  // 优先使用 message 字段（后端标准格式）
  if (data && data.message) {
    return data.message;
  }
  
  // 兼容可能的 error 字段
  if (data && data.error) {
    return data.error;
  }
  
  // 根据状态码返回默认消息
  switch (status) {
    case 400:
      return '请求参数错误';
    case 401:
      return '未登录或登录已过期';
    case 403:
      return '账号已过期，请联系管理员';
    case 404:
      return '请求的资源不存在';
    case 429:
      return '请求过于频繁，请稍后重试';
    case 500:
      return '服务器错误，请稍后重试';
    default:
      return defaultMessage;
  }
}

export default {
  handleApiError
};
```

### 2. 激活接口调用示例

```javascript
// pages/activate/activate.js
async function activateAccount(code, inviteCode) {
  try {
    const res = await wx.request({
      url: 'https://oddsmind.top/api/miniprogram/activate',
      method: 'POST',
      header: {
        'Content-Type': 'application/json'
      },
      data: {
        code: code,
        invite_code: inviteCode
      }
    });
    
    // ✅ 检查 success 字段
    if (res.data.success) {
      // 激活成功
      const { token, user } = res.data.data;
      
      // 保存 token
      wx.setStorageSync('token', token);
      wx.setStorageSync('user', user);
      
      // 跳转到首页
      wx.redirectTo({
        url: '/pages/index/index'
      });
    } else {
      // success: false 但 statusCode 是 200（不应该发生）
      wx.showToast({
        title: res.data.message || '激活失败',
        icon: 'none',
        duration: 2000
      });
    }
    
  } catch (error) {
    // ❌ 请求失败（statusCode 非 200）
    const errorMessage = handleApiError(error, '激活失败，请重试');
    
    wx.showToast({
      title: errorMessage,
      icon: 'none',
      duration: 3000
    });
    
    // 特殊处理：如果是 code 问题，重新登录
    if (errorMessage.includes('登录凭证已失效') || 
        errorMessage.includes('invalid code')) {
      setTimeout(() => {
        wx.reLaunch({
          url: '/pages/login/login'
        });
      }, 2000);
    }
  }
}
```

## 📊 错误码总结

| HTTP状态码 | success | message | 说明 |
|-----------|---------|---------|------|
| 200 | true | "OK" | 成功 |
| 400 | false | 具体错误信息 | 请求参数错误、验证失败 |
| 401 | false | 未登录相关 | 需要登录 |
| 403 | false | "账号已过期" | 权限问题 |
| 404 | false | 资源不存在 | 用户不存在等 |
| 429 | false | "请求过于频繁" | Rate Limiting |
| 500 | false | "请稍后重试" | 服务器错误 |

---

## 🎯 关键点

1. **后端使用 `message` 字段，不是 `error`！**
2. **所有响应都有 `success` 字段表示成功/失败**
3. **激活码错误统一返回"激活码无效或已失效"（安全考虑）**
4. **Rate Limiting: 登录10次/分钟，激活5次/分钟**
5. **微信 code 只能使用一次，重复使用会被拒绝**
