## 🔴 Critical 级别修复（已完成）

### 1. ✅ 时区问题 - 统一使用 UTC 时间

**问题：**
- 多处使用 `datetime.now()` 本地时间
- 数据库时区与应用时区不一致
- 可能导致账号过期验证失败

**修复：**
```python
# 所有时间比较统一使用 UTC
from datetime import datetime, timezone

# 1. 登录接口
now_utc = datetime.now(timezone.utc)
if expires_at < now_utc:
    return api_error("账号已过期")

# 2. JWT Token 验证
now_utc = datetime.now(timezone.utc)
if expires_at < now_utc:
    return None

# 3. 邀请码过期检查
now_utc = datetime.now(timezone.utc)
if expires_at < now_utc:
    return False, "邀请码已过期"
```

**影响文件：**
- `application/routes/miniprogram.py`
- `utils/jwt_helper.py`
- `utils/miniprogram_db.py`
- `auth.py`

### 2. ✅ 已激活用户可重复激活漏洞

**问题：**
- 数据库 UPDATE 没有检查 `is_activated = FALSE`
- 直接调用底层函数可以绕过应用层检查
- 已激活用户可以用新激活码延长有效期

**修复：**
```python
# 数据库层防护
cursor.execute("""
    UPDATE miniprogram_users
    SET is_activated = TRUE,
        activated_at = NOW(),
        expires_at = %s,
        invite_code_used = %s
    WHERE openid = %s
      AND is_activated = FALSE  -- ✅ 只激活未激活的用户
""", (account_expires_at, invite_code, openid))

# 检查更新结果
if cursor.rowcount == 0:
    # 检查是否已激活
    cursor.execute("SELECT is_activated FROM miniprogram_users WHERE openid = %s", (openid,))
    user_info = cursor.fetchone()
    if user_info and user_info['is_activated']:
        return False, "用户已激活，不能重复激活"
```

**影响文件：**
- `utils/miniprogram_db.py:334-373`

### 5. ✅ 微信 code 重放攻击防护

**问题：**
- 没有记录已使用的 code
- 攻击者可以重放 code 进行登录/激活

**修复：**
创建 `utils/rate_limiter.py`，实现 code 去重：

```python
def check_and_mark_wechat_code_used(code: str) -> bool:
    """检查并标记微信 code"""
    cache_key = f"wechat_code:{code}"
    
    if cache_key in _code_usage_cache:
        return False  # 已使用
    
    _code_usage_cache[cache_key] = time.time()  # 5分钟过期
    return True

# 在登录和激活接口中使用
if not check_and_mark_wechat_code_used(code):
    return api_error("登录凭证已失效，请重新登录", status=400)
```

**影响文件：**

### 6. ✅ 完善数据库事务管理

**问题：**
- `finally` 块中的 `conn.close()` 在 `try` 块中也有
- 异常处理不完善，可能导致连接池污染

**修复：**
```python
conn = None
cursor = None
try:
    conn = get_connection()
    cursor = conn.cursor()
    # ... 业务逻辑 ...
    conn.commit()
    return True, None
    
except Exception as e:
    if conn:
        try:
            conn.rollback()
        except:
            pass
    return False, str(e)
    
finally:
    if cursor:
        try:
            cursor.close()
        except:
            pass
    if conn:
        try:
            conn.close()
        except:
            pass
```

**影响文件：**
- `utils/miniprogram_db.py:252-414`

    # ...

@miniprogram_bp.route('/api/miniprogram/activate', methods=['POST'])

    # ...

### 9. ✅ 修复 JWT expires_at 逻辑

**问题：**
- 账号有效期 1 天，但 Token 有效期 7 天
- Token 在第 2-7 天仍有效，但账号已过期

**修复：**
```python
# Token 过期时间取 min(账号过期时间, 7天后)
token_max_exp = datetime.now(timezone.utc) + timedelta(days=JWT_EXPIRATION_DAYS)

if account_expires_at_str:
    account_expires_at = datetime.fromisoformat(account_expires_at_str)
    exp = min(account_expires_at, token_max_exp)  # ✅ 取最小值
else:
    exp = token_max_exp
```

**影响文件：**
- `utils/jwt_helper.py:30-81`
