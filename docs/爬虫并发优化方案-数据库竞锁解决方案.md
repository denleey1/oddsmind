# 爬虫并发优化方案 - 数据库竞锁解决方案

**优化日期**: 2025-12-28  
**目标**: 优化多线程爬虫的数据库操作，避免竞锁，提升性能

---

## 📋 问题分析

### 当前架构

1. **并发爬取**: 使用 `ThreadPoolExecutor`，最多15个线程同时爬取
2. **数据库连接池**: 使用 `PooledDB`，共享连接池
3. **数据保存**: 使用批量插入 `bulk_upsert_odds_changes`
4. **冲突处理**: 使用 `ON DUPLICATE KEY UPDATE`

### 潜在问题

#### 1. ⚠️ 数据库竞锁风险

**问题描述**:
- 多个线程同时调用 `bulk_upsert_odds_changes` 写入同一张表
- 批量插入时可能长时间持有表锁或行锁
- `ON DUPLICATE KEY UPDATE` 需要检查唯一键，可能产生锁等待

**影响**:
- 数据库锁等待时间增加
- 可能导致死锁
- 影响其他数据库操作（如API查询）

#### 2. ⚠️ 连接池压力

**问题描述**:
- 15个爬虫线程 + API请求线程同时使用连接池
- 连接池大小可能不足，导致连接等待

**影响**:
- 连接获取超时
- 任务阻塞

#### 3. ⚠️ 批量插入性能

**问题描述**:
- 每次批量插入可能包含数百到数千条记录
- 单次事务过大，锁持有时间长

**影响**:
- 其他操作被阻塞
- 事务回滚成本高

---

## 🔧 优化方案

### 方案一：批量写入队列（推荐）

**核心思想**: 将数据写入操作从爬虫线程中分离，使用队列缓冲，由专门的写入线程批量处理。

**优点**:
- 减少数据库连接竞争
- 合并多个小批量为大批量，提升效率
- 避免爬虫线程被数据库操作阻塞
- 更好的错误处理和重试机制

**实现步骤**:

#### 1. 创建批量写入队列管理器

**文件**: `database/batch_writer.py` (新建)

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
批量写入队列管理器
将数据库写入操作从爬虫线程中分离，使用队列缓冲，由专门的写入线程批量处理
"""

import time
import threading
from queue import Queue, Empty
from typing import List, Dict, Any, Optional
from collections import defaultdict
from datetime import datetime

from core.logger import get_logger
from database.manager import DatabaseManager
from database.models import OddsChangeModel, OverUnderOddsChangeModel, OddsModel

logger = get_logger(__name__)


class BatchWriter:
    """批量写入队列管理器"""
    
    def __init__(
        self,
        db_manager: DatabaseManager,
        batch_size: int = 500,  # 每批处理500条
        flush_interval: float = 2.0,  # 每2秒刷新一次
        max_queue_size: int = 10000  # 队列最大长度
    ):
        self.db_manager = db_manager
        self.batch_size = batch_size
        self.flush_interval = flush_interval
        self.max_queue_size = max_queue_size
        
        # 队列：存储待写入的数据
        self.odds_changes_queue: Queue = Queue(maxsize=max_queue_size)
        self.over_under_queue: Queue = Queue(maxsize=max_queue_size)
        self.odds_queue: Queue = Queue(maxsize=max_queue_size)
        
        # 写入线程
        self.writer_thread: Optional[threading.Thread] = None
        self.running = False
        self._lock = threading.Lock()
        
        # 统计信息
        self.stats = {
            'total_written': 0,
            'total_failed': 0,
            'queue_full_count': 0,
            'last_flush_time': None
        }
        self._stats_lock = threading.Lock()
        
        logger.info(f"BatchWriter initialized: batch_size={batch_size}, flush_interval={flush_interval}s")
    
    def start(self):
        """启动写入线程"""
        if self.running:
            logger.warning("BatchWriter is already running")
            return
        
        self.running = True
        self.writer_thread = threading.Thread(target=self._writer_loop, daemon=True, name="BatchWriter")
        self.writer_thread.start()
        logger.info("BatchWriter started")
    
    def stop(self, timeout: float = 30.0):
        """停止写入线程，等待队列清空"""
        if not self.running:
            return
        
        logger.info("Stopping BatchWriter, flushing remaining data...")
        self.running = False
        
        if self.writer_thread:
            self.writer_thread.join(timeout=timeout)
        
        # 最后刷新一次
        self._flush_all()
        logger.info("BatchWriter stopped")
    
    def enqueue_odds_changes(self, odds_changes: List[OddsChangeModel]) -> bool:
        """
        将赔率变化数据加入队列（非阻塞）
        
        Returns:
            True if enqueued successfully, False if queue is full
        """
        try:
            self.odds_changes_queue.put_nowait(odds_changes)
            return True
        except:
            with self._stats_lock:
                self.stats['queue_full_count'] += 1
            logger.warning(f"Odds changes queue is full, dropping {len(odds_changes)} records")
            return False
    
    def enqueue_over_under(self, changes: List[OverUnderOddsChangeModel]) -> bool:
        """将大小球赔率变化数据加入队列"""
        try:
            self.over_under_queue.put_nowait(changes)
            return True
        except:
            logger.warning(f"Over/under queue is full, dropping {len(changes)} records")
            return False
    
    def enqueue_odds(self, match_id: int, odds_data: Dict[str, Any]) -> bool:
        """将赔率数据加入队列"""
        try:
            self.odds_queue.put_nowait((match_id, odds_data))
            return True
        except:
            logger.warning(f"Odds queue is full, dropping match {match_id}")
            return False
    
    def _writer_loop(self):
        """写入线程主循环"""
        logger.info("BatchWriter thread started")
        
        last_flush = time.time()
        
        while self.running:
            try:
                current_time = time.time()
                time_since_flush = current_time - last_flush
                
                # 检查是否需要刷新（时间间隔或队列大小）
                should_flush = (
                    time_since_flush >= self.flush_interval or
                    self.odds_changes_queue.qsize() >= self.batch_size or
                    self.over_under_queue.qsize() >= self.batch_size or
                    self.odds_queue.qsize() >= self.batch_size
                )
                
                if should_flush:
                    self._flush_all()
                    last_flush = current_time
                else:
                    # 短暂休眠，避免CPU占用过高
                    time.sleep(0.1)
                    
            except Exception as e:
                logger.error(f"Error in BatchWriter loop: {e}", exc_info=True)
                time.sleep(1.0)
        
        logger.info("BatchWriter thread stopped")
    
    def _flush_all(self):
        """刷新所有队列，批量写入数据库"""
        try:
            # 收集所有待写入的数据
            all_odds_changes = []
            all_over_under = []
            odds_batch = {}
            
            # 从队列中取出数据（非阻塞）
            while True:
                try:
                    odds_changes = self.odds_changes_queue.get_nowait()
                    if isinstance(odds_changes, list):
                        all_odds_changes.extend(odds_changes)
                except Empty:
                    break
            
            while True:
                try:
                    over_under = self.over_under_queue.get_nowait()
                    if isinstance(over_under, list):
                        all_over_under.extend(over_under)
                except Empty:
                    break
            
            while True:
                try:
                    match_id, odds_data = self.odds_queue.get_nowait()
                    odds_batch[match_id] = odds_data
                except Empty:
                    break
            
            # 批量写入数据库
            written_count = 0
            
            if all_odds_changes:
                # 分批写入，避免单次事务过大
                for i in range(0, len(all_odds_changes), self.batch_size):
                    batch = all_odds_changes[i:i + self.batch_size]
                    try:
                        count = self.db_manager.bulk_upsert_odds_changes(batch)
                        written_count += count
                    except Exception as e:
                        logger.error(f"Failed to write odds_changes batch: {e}", exc_info=True)
                        with self._stats_lock:
                            self.stats['total_failed'] += len(batch)
            
            if all_over_under:
                for i in range(0, len(all_over_under), self.batch_size):
                    batch = all_over_under[i:i + self.batch_size]
                    try:
                        count = self.db_manager.bulk_upsert_over_under_odds_changes(batch)
                        written_count += count
                    except Exception as e:
                        logger.error(f"Failed to write over_under batch: {e}", exc_info=True)
                        with self._stats_lock:
                            self.stats['total_failed'] += len(batch)
            
            if odds_batch:
                try:
                    results = self.db_manager.store_multiple_odds_data(odds_batch)
                    written_count += sum(results.values())
                except Exception as e:
                    logger.error(f"Failed to write odds batch: {e}", exc_info=True)
                    with self._stats_lock:
                        self.stats['total_failed'] += len(odds_batch)
            
            # 更新统计信息
            if written_count > 0:
                with self._stats_lock:
                    self.stats['total_written'] += written_count
                    self.stats['last_flush_time'] = datetime.now()
                
                logger.debug(f"BatchWriter flushed: {written_count} records written")
            
        except Exception as e:
            logger.error(f"Error flushing queues: {e}", exc_info=True)
    
    def get_stats(self) -> Dict[str, Any]:
        """获取统计信息"""
        with self._stats_lock:
            stats = self.stats.copy()
        
        stats.update({
            'odds_changes_queue_size': self.odds_changes_queue.qsize(),
            'over_under_queue_size': self.over_under_queue.qsize(),
            'odds_queue_size': self.odds_queue.qsize(),
            'is_running': self.running
        })
        
        return stats
    
    def wait_for_empty(self, timeout: float = 60.0) -> bool:
        """等待队列清空"""
        start_time = time.time()
        
        while time.time() - start_time < timeout:
            if (self.odds_changes_queue.empty() and 
                self.over_under_queue.empty() and 
                self.odds_queue.empty()):
                return True
            time.sleep(0.5)
        
        return False
```

### 方案三：优化批量插入SQL

**文件**: `database/manager.py`

#### 1. 使用更高效的批量插入

**当前实现**:
```python
# 使用 execute_many，可能不是最优的
affected_rows = self.odds_changes.db.execute_many(query, data_to_save)
```

**优化实现**:
```python
def bulk_upsert_odds_changes_optimized(self, odds_changes: List[OddsChangeModel]) -> int:
    """
    优化的批量插入，使用更高效的SQL和事务控制
    """
    if not odds_changes:
        return 0
    
    # 确保公司存在
    company_ids = set(change.company_id for change in odds_changes if change.company_id)
    if company_ids:
        self._ensure_companies_exist(company_ids)
    
    # 分批处理，每批最多500条
    batch_size = 500
    total_affected = 0
    
    for i in range(0, len(odds_changes), batch_size):
        batch = odds_changes[i:i + batch_size]
        
        try:
            # 使用事务确保原子性
            conn = get_connection()
            try:
                cursor = conn.cursor()
                
                # 构建批量插入SQL（VALUES子句）
                values_list = []
                params_list = []
                
                for change in batch:
                    change_dict = change.to_db_dict()
                    values_list.append(
                        "(%(match_id)s, %(company_id)s, %(initial_home)s, %(initial_draw)s, "
                        "%(initial_away)s, %(initial_return_rate)s, %(current_home)s, "
                        "%(current_draw)s, %(current_away)s, %(current_return_rate)s, %(last_updated)s)"
                    )
                    params_list.append(change_dict)
                
                # 构建完整SQL
                query = f"""
                    INSERT INTO odds_changes (
                        match_id, company_id, 
                        initial_home, initial_draw, initial_away, initial_return_rate,
                        current_home, current_draw, current_away, current_return_rate, 
                        last_updated
                    ) VALUES {', '.join(values_list)}
                    ON DUPLICATE KEY UPDATE
                        initial_home = VALUES(initial_home),
                        initial_draw = VALUES(initial_draw),
                        initial_away = VALUES(initial_away),
                        initial_return_rate = VALUES(initial_return_rate),
                        current_home = VALUES(current_home),
                        current_draw = VALUES(current_draw),
                        current_away = VALUES(current_away),
                        current_return_rate = VALUES(current_return_rate),
                        last_updated = VALUES(last_updated)
                """
                
                # 执行批量插入
                # 注意：pymysql的execute不支持多行VALUES，需要使用executemany
                # 但我们可以使用更高效的方式
                affected = cursor.executemany(
                    """
                    INSERT INTO odds_changes (
                        match_id, company_id, 
                        initial_home, initial_draw, initial_away, initial_return_rate,
                        current_home, current_draw, current_away, current_return_rate, 
                        last_updated
                    ) VALUES (
                        %(match_id)s, %(company_id)s,
                        %(initial_home)s, %(initial_draw)s, %(initial_away)s, %(initial_return_rate)s,
                        %(current_home)s, %(current_draw)s, %(current_away)s, %(current_return_rate)s,
                        %(last_updated)s
                    )
                    ON DUPLICATE KEY UPDATE
                        initial_home = VALUES(initial_home),
                        initial_draw = VALUES(initial_draw),
                        initial_away = VALUES(initial_away),
                        initial_return_rate = VALUES(initial_return_rate),
                        current_home = VALUES(current_home),
                        current_draw = VALUES(current_draw),
                        current_away = VALUES(current_away),
                        current_return_rate = VALUES(current_return_rate),
                        last_updated = VALUES(last_updated)
                    """,
                    params_list
                )
                
                conn.commit()
                total_affected += affected
                
            finally:
                cursor.close()
                conn.close()
                
        except Exception as e:
            logger.error(f"Failed to bulk insert odds_changes batch {i//batch_size + 1}: {e}", exc_info=True)
            if conn:
                try:
                    conn.rollback()
                except:
                    pass
    
    logger.info(f"Successfully bulk inserted {total_affected} odds_changes records")
    return total_affected
```

### 方案四：使用数据库行级锁（高级）

**仅在必要时使用，避免过度锁定**

**文件**: `database/manager.py`

```python
def bulk_upsert_odds_changes_with_lock(self, odds_changes: List[OddsChangeModel]) -> int:
    """
    使用行级锁的批量插入（用于高并发场景）
    """
    if not odds_changes:
        return 0
    
    # 按 match_id 分组，减少锁竞争
    grouped = defaultdict(list)
    for change in odds_changes:
        grouped[change.match_id].append(change)
    
    total_affected = 0
    
    # 对每个 match_id 单独处理，使用行级锁
    for match_id, changes in grouped.items():
        try:
            conn = get_connection()
            try:
                cursor = conn.cursor()
                
                # 使用 SELECT FOR UPDATE 锁定相关行（可选）
                # 注意：这可能会增加锁等待时间，仅在必要时使用
                # cursor.execute(
                #     "SELECT match_id FROM odds_changes WHERE match_id = %s FOR UPDATE",
                #     (match_id,)
                # )
                
                # 批量插入该比赛的所有赔率变化
                params_list = [change.to_db_dict() for change in changes]
                
                affected = cursor.executemany(
                    """
                    INSERT INTO odds_changes (...) VALUES (...)
                    ON DUPLICATE KEY UPDATE ...
                    """,
                    params_list
                )
                
                conn.commit()
                total_affected += affected
                
            finally:
                cursor.close()
                conn.close()
                
        except Exception as e:
            logger.error(f"Failed to insert odds_changes for match {match_id}: {e}")
    
    return total_affected
```

## ⚠️ 注意事项

### 1. 数据一致性

- 批量写入队列可能导致数据延迟（最多2秒）
- 如果对实时性要求高，可以降低 `flush_interval`

### 2. 内存使用

- 队列会占用内存
- 设置合理的 `max_queue_size`

### 3. 错误处理

- 队列满时的处理策略（丢弃或阻塞）
- 写入失败的重试机制

### 4. 优雅关闭

- 应用关闭时等待队列清空
- 避免数据丢失
