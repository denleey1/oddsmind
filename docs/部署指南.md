# OddsMind 部署指南

本文档提供两种部署方式：
1. **Git 仓库同步部署** - 适合开发和多环境部署
2. **Docker 容器部署** - 适合生产环境，一键启动

---

## 📦 方案一：Git 仓库同步部署

### 1.1 初始化 Git 仓库

```bash
# 进入项目目录
cd /home/ubuntu/oddsmind

# 初始化 Git 仓库
git init

# 添加所有文件
git add .

# 提交初始版本
git commit -m "Initial commit: OddsMind application"

# 查看提交历史
git log
```

### 1.2 创建远程仓库（GitHub/GitLab/Gitee）

#### 使用 GitHub

1. 在 GitHub 创建新仓库（例如：`oddsmind`）
2. 添加远程仓库：

```bash
# 添加远程仓库
git remote add origin https://github.com/yourusername/oddsmind.git

# 或者使用 SSH
git remote add origin git@github.com:yourusername/oddsmind.git

# 查看远程仓库
git remote -v
```

3. 推送代码：

```bash
# 推送主分支
git branch -M main
git push -u origin main
```

#### 使用 Gitee（码云）

```bash
# 添加 Gitee 远程仓库
git remote add gitee https://gitee.com/yourusername/oddsmind.git

# 推送代码
git push -u gitee main
```

### 1.3 在其他服务器同步代码

```bash
# 克隆仓库
git clone https://github.com/yourusername/oddsmind.git
# 或
git clone git@github.com:yourusername/oddsmind.git

# 进入项目目录
cd oddsmind

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp oddsmind.env.example oddsmind.env
# 编辑 oddsmind.env，填入实际配置

# 启动应用
python app.py
```

### 1.4 更新代码

```bash
# 在开发服务器上提交更改
git add .
git commit -m "描述你的更改"
git push origin main

# 在生产服务器上拉取更新
cd /path/to/oddsmind
git pull origin main

# 重启服务
systemctl restart oddsmind.service
```

## 🐳 方案二：Docker 容器部署（推荐）

### 2.1 构建 Docker 镜像

#### 方式一：本地构建

```bash
# 进入项目目录
cd /home/ubuntu/oddsmind

# 构建镜像
docker build -t oddsmind:latest .

# 查看镜像
docker images | grep oddsmind
```

#### 方式二：使用 Docker Compose（推荐）

```bash
# 使用 docker-compose 构建并启动
docker-compose up -d --build

# 查看运行状态
docker-compose ps

# 查看日志
docker-compose logs -f oddsmind
```

### 2.2 配置环境变量

创建 `.env` 文件（或使用 `docker-compose.yml` 中的环境变量）：

```bash
# 数据库配置
DB_HOST=mysql
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_secure_password
DB_NAME=oddsmind

# Redis 配置
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_DB=0

# 应用配置
FLASK_ENV=production
ODDSMIND_PORT=8889

# 微信小程序配置
WECHAT_APPID=your_appid
WECHAT_APPSECRET=your_secret

# 其他配置
WEB_ACCESS_PASSWORD=your_web_password
SESSION_SECRET_KEY=your_session_secret
```

### 2.3 启动服务

```bash
# 启动所有服务（MySQL + Redis + 应用）
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 停止并删除数据卷（谨慎使用）
docker-compose down -v
```

### 2.4 导出和导入镜像

#### 导出镜像

```bash
# 导出镜像为 tar 文件
docker save -o oddsmind-latest.tar oddsmind:latest

# 压缩镜像文件（可选）
gzip oddsmind-latest.tar
```

#### 导入镜像

```bash
# 在其他服务器上导入镜像
docker load -i oddsmind-latest.tar

# 或从压缩文件导入
gunzip -c oddsmind-latest.tar.gz | docker load
```

#### 使用镜像启动容器

```bash
# 创建 docker-compose.yml（或使用已有的）
# 修改镜像名称为本地镜像
# 然后启动
docker-compose up -d
```

### 2.5 推送到 Docker Hub

```bash
# 登录 Docker Hub
docker login

# 标记镜像
docker tag oddsmind:latest yourusername/oddsmind:latest

# 推送镜像
docker push yourusername/oddsmind:latest

# 在其他服务器拉取
docker pull yourusername/oddsmind:latest
```

## 🚀 快速部署脚本

### 3.1 Git 部署脚本

创建 `deploy-git.sh`：

```bash
#!/bin/bash
# Git 部署脚本

set -e

echo "开始部署 OddsMind..."

# 拉取最新代码
echo "拉取最新代码..."
git pull origin main

# 激活虚拟环境
source venv/bin/activate

# 更新依赖
echo "更新依赖..."
pip install -r requirements.txt

# 重启服务
echo "重启服务..."
systemctl restart oddsmind.service

# 检查服务状态
sleep 3
systemctl status oddsmind.service

echo "部署完成！"
```

使用：

```bash
chmod +x deploy-git.sh
./deploy-git.sh
```

### 3.2 Docker 部署脚本

创建 `deploy-docker.sh`：

```bash
#!/bin/bash
# Docker 部署脚本

set -e

echo "开始部署 OddsMind..."

# 拉取最新代码（如果使用 Git）
# git pull origin main

# 停止旧容器
echo "停止旧容器..."
docker-compose down

# 构建新镜像
echo "构建新镜像..."
docker-compose build --no-cache

# 启动服务
echo "启动服务..."
docker-compose up -d

# 等待服务启动
sleep 10

# 检查服务状态
docker-compose ps

# 查看日志
echo "查看应用日志..."
docker-compose logs --tail=50 oddsmind

echo "部署完成！"
```

使用：

```bash
chmod +x deploy-docker.sh
./deploy-docker.sh
```

## 🔧 常见问题

### 问题 1：Docker 构建失败

**原因：** 依赖安装失败或系统依赖缺失

**解决：**
```bash
# 检查 Dockerfile 中的系统依赖
# 确保所有依赖都在 Dockerfile 中安装

# 清理构建缓存重新构建
docker-compose build --no-cache
```

### 问题 2：数据库连接失败

**原因：** 数据库配置错误或网络问题

**解决：**
```bash
# 检查环境变量
docker-compose exec oddsmind env | grep DB_

# 检查数据库服务
docker-compose ps mysql

# 测试数据库连接
docker-compose exec oddsmind python -c "from database.connection import get_connection; print(get_connection())"
```

### 问题 3：Redis 连接失败

**原因：** Redis 配置错误

**解决：**
```bash
# 检查 Redis 服务
docker-compose ps redis

# 测试 Redis 连接
docker-compose exec oddsmind python -c "import redis; r = redis.Redis(host='redis', port=6379); print(r.ping())"
```

### 问题 4：端口冲突

**原因：** 端口已被占用

**解决：**
```bash
# 检查端口占用
netstat -tulpn | grep 8889

# 修改 docker-compose.yml 中的端口映射
# 例如：将 "8889:8889" 改为 "8890:8889"
```

## 📝 维护命令

### Docker 维护

```bash
# 查看日志
docker-compose logs -f oddsmind

# 进入容器
docker-compose exec oddsmind bash

# 重启服务
docker-compose restart oddsmind

# 更新代码并重启
docker-compose up -d --build

# 备份数据
docker-compose exec mysql mysqldump -u root -p oddsmind > backup.sql

# 清理未使用的镜像
docker image prune -a
```

### Git 维护

```bash
# 查看提交历史
git log --oneline

# 创建新分支
git checkout -b feature/new-feature

# 合并分支
git merge feature/new-feature

# 回退到指定版本
git reset --hard <commit-hash>

# 查看文件变更
git diff
```

## 🎯 推荐方案

**开发环境：** 使用 Git 仓库同步  
**生产环境：** 使用 Docker 容器部署

**优势对比：**

| 方案 | 优势 | 适用场景 |
|------|------|---------|
| Git | 灵活、易于调试、代码版本控制 | 开发、测试环境 |
| Docker | 环境一致、一键部署、易于扩展 | 生产环境、多服务器部署 |
