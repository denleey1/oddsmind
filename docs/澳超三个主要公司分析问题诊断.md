# 澳超三个主要公司分析问题诊断

## 问题描述

用户反馈在分析里看不到马会（432）、澳门（80）、威廉希尔（115）这三个主要公司的数据。

## 诊断结果

### 1. 数据完整性检查

✅ **赔率数据**：
- 马会（432）：56/56场比赛有赔率数据（100%覆盖率）
- 澳门（80）：56/56场比赛有赔率数据（100%覆盖率）
- 威廉希尔（115）：56/56场比赛有赔率数据（100%覆盖率）

✅ **广义实力数据**：
- 马会（432）：12支球队，312条记录（已修复season字段为'2025-2026'）
- 澳门（80）：12支球队，312条记录（已修复season字段为'2025-2026'）
- 威廉希尔（115）：12支球队，312条记录（已修复season字段为'2025-2026'）

✅ **分析结果数据**：
- 马会（432）：4条分析结果
- 澳门（80）：4条分析结果
- 威廉希尔（115）：4条分析结果

### 2. 问题根源

从代码分析看，`extract_company_complete_data`函数（`application/services/match_analysis_service.py`）会从API返回的`companyAnalyses`中提取公司数据，并且只提取`COMPANY_IDS`中定义的公司：

```python
COMPANY_IDS = {
    '马会': 432,      # HKJC
    '澳门': 80,       # Macau
    '威廉': 115,      # William Hill
    '平博': 281,      # Pinnacle
    'Interwetten': 190  # Interwetten (塞浦路斯)
}
```

**关键问题**：如果这三个公司在分析时因为缺少广义实力数据而被跳过，它们就不会出现在`companyAnalyses`中，导致前端看不到。

### 3. 分析逻辑检查

从`odds_analysis/main_analyzer.py`的代码看，分析时会检查是否有广义实力数据：

```python
if company_id in power_ratings:
    # 如果有实力数据，则合并
    odds_with_power[company_id].update(power_ratings[company_id])
else:
    # 如果没有实力数据
    # 检查是否为联赛初期（前4轮），如果是，则使用默认值继续分析
    round_number = match_info.get('round_number')
    if round_number is None or round_number <= 4:
        # 使用默认值继续分析
    else:
        # 如果不是联赛初期（> 4轮），则跳过这家公司
        del odds_with_power[company_id]
```

**问题**：如果比赛轮次 > 4轮，且这三个公司没有广义实力数据，它们就会被跳过，不会出现在分析结果中。

### 4. 已修复的问题

✅ **season字段为NULL**：
- 问题：这三个公司的广义实力数据的`season`字段都是`NULL`
- 修复：已更新为`'2025-2026'`
- 影响：现在查询时应该能正确匹配到这些数据

### 5. 可能的原因

1. **分析时没有找到广义实力数据**：
   - 虽然数据库中有数据，但查询时可能因为season字段不匹配而找不到
   - 或者查询时没有正确匹配到这些数据

2. **分析结果被过滤**：
   - 如果分析时这三个公司因为缺少广义实力数据而被跳过，它们就不会出现在分析结果中

3. **前端显示问题**：
   - 如果API返回的数据中有这三个公司，但前端没有正确显示
