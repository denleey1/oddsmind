# 微信小程序配置（必需）
WECHAT_APPID=your_wechat_appid
WECHAT_APPSECRET=your_wechat_appsecret

## 📝 使用说明

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 创建数据库表

数据库表会在应用启动时自动创建（如果使用数据库初始化脚本）。

### 3. 创建邀请码

```bash
# 创建单个邀请码（默认有效期365天）
python tools/manage_invite_codes.py create --max-uses 1 --expires-days 365 --created-by admin

# 创建多个使用次数的邀请码
python tools/manage_invite_codes.py create --max-uses 10 --expires-days 30 --created-by admin

# 查看所有邀请码
python tools/manage_invite_codes.py list

# 查看激活的邀请码
python tools/manage_invite_codes.py list --active-only

# 查看邀请码信息
python tools/manage_invite_codes.py info <邀请码>

# 禁用邀请码
python tools/manage_invite_codes.py disable <邀请码>
```

### 4. API 接口使用

#### 登录接口
```bash
POST /api/miniprogram/login
Content-Type: application/json

{
    "code": "wx.login()获取的code"
}
```

#### 激活接口
```bash
POST /api/miniprogram/activate
Content-Type: application/json

{
    "code": "wx.login()获取的code",
    "invite_code": "INVITE123"
}
```

#### 获取用户信息
```bash
GET /api/miniprogram/user
Authorization: Bearer <jwt_token>
```

## ⚠️ 注意事项

1. **环境变量配置**
   - 必须配置 `JWT_SECRET`、`WECHAT_APPID`、`WECHAT_APPSECRET`
   - `JWT_SECRET` 应该是一个长随机字符串（至少32字符）

2. **数据库表创建**
   - 表会在首次启动时自动创建
   - 如果表已存在，不会重复创建（使用 `CREATE TABLE IF NOT EXISTS`）

3. **向后兼容**
   - 现有接口不受影响
   - `login_required` 装饰器默认仍然直接通过（向后兼容）
   - 只有携带 JWT Token 的请求才会进行验证

4. **微信 API 限制**
   - 微信 API 有调用频率限制
   - 建议实现请求缓存（如果需要）
