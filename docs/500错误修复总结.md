## 🐛 问题原因

**错误信息:**
```
TypeError: error() takes 1 positional argument but 2 were given
```

**原因:**
`api_error()` 函数的签名是：
```python
def error(message: str, *, status: int = 400, data: Any = None):
```

注意 `status` 参数前面有 `*`，这意味着它必须是关键字参数，不能是位置参数。

**错误的调用方式:**
```python
return api_error("错误信息", 400)  # ❌ 错误
```

**正确的调用方式:**
```python
return api_error("错误信息", status=400)  # ✅ 正确
```
