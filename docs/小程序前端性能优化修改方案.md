# 小程序前端性能优化修改方案

**优化日期**: 2025-12-28  
**优化内容**: 比赛详情接口性能优化 - 泊松预测延迟加载

---

## 📋 修改概览

### 优化前
- 比赛详情接口包含泊松预测，响应时间 **3-8秒**
- 用户打开详情页需要等待很长时间

### 优化后
- 比赛详情接口不包含泊松预测，响应时间 **0.5-2秒**
- 泊松预测改为按需加载，用户点击或滚动到相关区域时才加载

---

#### 2.3 添加加载泊松预测的方法

**在页面 JS 中添加以下新方法**：

```javascript
/**
 * 加载泊松预测（按需加载）
 * 可以在用户点击"查看预测"按钮或滚动到相关区域时调用
 */
async loadPoissonPrediction() {
  const matchId = this.data.matchId || this.data.matchDetail?.matchId
  
  if (!matchId) {
    console.error('无法加载泊松预测：缺少比赛ID')
    return
  }
  
  // 如果已经加载过，不再重复加载
  if (this.data.poissonLoaded) {
    console.log('泊松预测已加载，跳过')
    return
  }
  
  // 如果正在加载，跳过
  if (this.data.poissonLoading) {
    console.log('泊松预测正在加载中，跳过')
    return
  }
  
  try {
    this.setData({
      poissonLoading: true,
      poissonError: null
    })
    
    // 调用泊松预测接口
    const response = await api.get(`/matches/${matchId}/poisson`)
    // 或者: const response = await api.getMatchPoissonPrediction(matchId)
    // 或者公共接口: const response = await api.getPublicMatchPoissonPrediction(matchId)
    
    if (response.success && response.data) {
      this.setData({
        poissonPrediction: response.data,
        poissonLoaded: true,
        poissonLoading: false
      })
    } else {
      throw new Error(response.error || '加载泊松预测失败')
    }
  } catch (error) {
    console.error('加载泊松预测失败:', error)
    this.setData({
      poissonLoading: false,
      poissonError: error.message || '加载泊松预测失败，请稍后重试'
    })
    
    wx.showToast({
      title: '加载预测失败',
      icon: 'none',
      duration: 2000
    })
  }
},

/**
 * 手动触发加载泊松预测（用户点击按钮）
 */
onLoadPoissonTap() {
  this.loadPoissonPrediction()
},

/**
 * 当泊松预测区域进入可视区域时自动加载（懒加载）
 * 需要在 WXML 中使用 intersection-observer 或 scroll-view 触发
 */
onPoissonSectionVisible() {
  if (!this.data.poissonLoaded && !this.data.poissonLoading) {
    this.loadPoissonPrediction()
  }
}
```

    matchDetail: null,

      })

      if (response.success && response.data) {
        this.setData({
          poissonPrediction: response.data,
          poissonLoaded: true,
          poissonLoading: false
        })
      } else {
        throw new Error(response.error || '加载泊松预测失败')
      }
    } catch (error) {
      console.error('加载泊松预测失败:', error)
      this.setData({
        poissonLoading: false,
        poissonError: error.message || '加载泊松预测失败，请稍后重试'
      })
      
      wx.showToast({
        title: '加载预测失败',
        icon: 'none',
        duration: 2000
      })
    }
  },

  /**
   * 用户点击"查看预测"按钮

#### 3.3 使用懒加载（可选）

**如果希望滚动到相关区域时自动加载，可以使用 `intersection-observer`**：

```xml
<!-- 使用 intersection-observer 实现懒加载 -->
<intersection-observer 
  bind:intersect="onPoissonSectionVisible"
  threshold="0.5"
>
  <view class="poisson-section">
    <!-- 泊松预测内容 -->
    <!-- ... 同上 ... -->
  </view>
</intersection-observer>
```

**或者使用 `scroll-view` 的 `bindscrolltolower`**：

```xml
<scroll-view 
  scroll-y 
  class="match-detail-scroll"
  bindscrolltolower="onPoissonSectionVisible"
>
  <!-- 其他内容 -->
  
  <view class="poisson-section">
    <!-- 泊松预测内容 -->
    <!-- ... 同上 ... -->
  </view>
</scroll-view>
```
