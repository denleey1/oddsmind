## 🔍 查看完整列表

运行以下命令查看完整列表：

```bash
python3 -c "
import sys
sys.path.insert(0, '.')
from config.leagues_config import LEAGUES_CONFIG
import re

def extract_id(fn):
    m = re.search(r's(\d+)', fn)
    return int(m.group(1)) if m else None

leagues = sorted(LEAGUES_CONFIG.items(), 
                 key=lambda x: extract_id(x[1].league_filename) or 9999)

for i, (code, info) in enumerate(leagues, 1):
    lid = extract_id(info.league_filename)
    print(f'{i:3d}. ID:{lid:5s} | {info.country:20s} | {info.name_cn:30s} | {info.name_en}')
"
```
