    try:
        response = self.connection_pool.get(odds_url)
        # ... 处理响应
    except (NetworkError, ContentError) as e:
        # 所有错误都重试

self.invalid_match_ids: Set[int] = set()

**代码变更**:
```python
# 优化前：速率限制超时直接跳过
if not self.concurrent_rate_limiter.acquire(timeout=5.0):
    self.logger.warning(f"Rate limit timeout, skipping")
    continue

# 优化后：延迟重试
max_rate_limit_retries = 3
while rate_limit_retry_count < max_rate_limit_retries:
    if self.concurrent_rate_limiter.acquire(timeout=5.0):
        break
    else:
        retry_delay = 2.0 + (rate_limit_retry_count * 0.5)
        time.sleep(retry_delay)
        rate_limit_retry_count += 1
```

## ⚠️ 注意事项

### 1. 无效ID缓存

- 缓存是内存中的，应用重启后会清空
- 如果需要持久化，可以考虑使用Redis或数据库
- 定期清理过期缓存（如比赛结束后）

### 2. 速率限制重试

- 最多重试3次，避免无限等待
- 如果3次都失败，仍然会跳过（避免阻塞）
- 可以根据实际情况调整重试次数和延迟

### 3. 并发数调整

- 当前设置为10个并发，可以根据服务器资源调整
- 如果服务器资源充足，可以增加到15-20个
