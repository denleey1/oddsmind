# 数据库表数据比较指南

## 概述

用于比较两个服务器上同一个表的数据是否完全一致。支持直接连接比较和导出后比较两种方式。

## 使用方法

### 方法1：直接连接两个数据库比较（推荐，适合小表）

```bash
# 使用环境变量配置（推荐）
python tools/compare_table_data.py \
    --table team_power_ratings \
    --use-env \
    --host2 192.168.1.100 \
    --user2 root \
    --password2 your_password \
    --database2 oddsmind \
    --detailed

# 手动指定两个数据库配置
python tools/compare_table_data.py \
    --table team_power_ratings \
    --host1 localhost --user1 root --password1 pass1 --database1 oddsmind \
    --host2 192.168.1.100 --user2 root --password2 pass2 --database2 oddsmind \
    --detailed
```

### 方法2：导出后本地比较（适合大表或网络不稳定）

#### 步骤1：分别导出两个表的数据

```bash
# 导出服务器1的数据
python tools/compare_table_data.py \
    --table team_power_ratings \
    --use-env \
    --export-only \
    --output1 team_power_ratings_server1.sql

# 导出服务器2的数据（需要SSH到服务器2或使用远程连接）
python tools/compare_table_data.py \
    --table team_power_ratings \
    --host2 192.168.1.100 \
    --user2 root \
    --password2 pass2 \
    --database2 oddsmind \
    --export-only \
    --output2 team_power_ratings_server2.sql
```

#### 步骤2：导入到本地数据库并比较

```bash
# 导入到本地数据库（使用不同的数据库名或表名）
mysql -u root -p oddsmind < team_power_ratings_server1.sql
mysql -u root -p oddsmind < team_power_ratings_server2.sql

# 或者导入到临时表
mysql -u root -p oddsmind -e "CREATE TABLE team_power_ratings_server1 LIKE team_power_ratings;"
mysql -u root -p oddsmind < team_power_ratings_server1.sql
mysql -u root -p oddsmind -e "CREATE TABLE team_power_ratings_server2 LIKE team_power_ratings;"
mysql -u root -p oddsmind < team_power_ratings_server2.sql

# 然后比较
python tools/compare_table_data.py \
    --table team_power_ratings_server1 \
    --use-env \
    --host2 localhost \
    --user2 root \
    --password2 your_password \
    --database2 oddsmind \
    --table2 team_power_ratings_server2
```

### 方法3：使用MySQL的mysqldump导出后比较

```bash
# 导出服务器1的数据
mysqldump -h server1 -u root -p oddsmind team_power_ratings > server1_team_power_ratings.sql

# 导出服务器2的数据
mysqldump -h server2 -u root -p oddsmind team_power_ratings > server2_team_power_ratings.sql

# 使用diff比较（只比较数据，忽略格式）
mysqldump --skip-comments --skip-extended-insert -h server1 -u root -p oddsmind team_power_ratings > server1_clean.sql
mysqldump --skip-comments --skip-extended-insert -h server2 -u root -p odds2 oddsmind team_power_ratings > server2_clean.sql
diff server1_clean.sql server2_clean.sql
```

## 常用选项

### 忽略某些列的比较

如果表中有 `updated_at` 等时间戳字段，可能每次比较都不同，可以忽略：

```bash
python tools/compare_table_data.py \
    --table team_power_ratings \
    --use-env \
    --host2 192.168.1.100 \
    --ignore-columns updated_at created_at
```

### 显示详细差异

```bash
python tools/compare_table_data.py \
    --table team_power_ratings \
    --use-env \
    --host2 192.168.1.100 \
    --detailed
```

## 注意事项

1. **大表处理**：
   - 如果表很大（>100万行），建议使用导出后比较的方式
   - 或者使用 `--ignore-columns` 忽略不重要的列

2. **网络稳定性**：
   - 如果两个服务器之间网络不稳定，建议先导出再比较

3. **时区问题**：
   - 如果表中有时间字段，确保两个数据库的时区设置一致
   - 或者使用 `--ignore-columns` 忽略时间字段

4. **性能考虑**：
   - 比较过程会读取整个表到内存，确保有足够的内存
   - 对于超大表，可以考虑分批比较

5. **安全性**：
   - 不要在命令行中直接输入密码，使用环境变量或配置文件
   - 导出文件包含敏感数据，注意保护

## 快速比较脚本示例

创建一个快速比较脚本 `quick_compare.sh`：

```bash
#!/bin/bash
TABLE_NAME="team_power_ratings"
SERVER2_HOST="192.168.1.100"
SERVER2_USER="root"
SERVER2_PASS="your_password"

python tools/compare_table_data.py \
    --table $TABLE_NAME \
    --use-env \
    --host2 $SERVER2_HOST \
    --user2 $SERVER2_USER \
    --password2 $SERVER2_PASS \
    --database2 oddsmind \
    --detailed \
    --ignore-columns updated_at
```

## 故障排查

### 连接失败
- 检查网络连接
- 检查防火墙设置
- 确认数据库用户有远程连接权限

### 内存不足
- 使用导出后比较的方式
- 或者分批比较（需要修改脚本）

### 时区不一致
- 检查两个数据库的时区设置：`SELECT @@global.time_zone, @@session.time_zone;`
- 使用 `--ignore-columns` 忽略时间字段
