# 激活码有效期和使用记录说明

## ✅ 已实现的功能

### 1. 激活码对应不同的账号有效期

**数据库字段：**
- `account_expires_days`：账号有效期（天数）
  - `1` = 1天
  - `7` = 1周
  - `30` = 1个月
  - `365` = 1年（默认）

**实现逻辑：**
```python
# utils/miniprogram_db.py
def get_invite_code_expires_days(code: str) -> int:
    """从数据库读取账号有效期"""
    invite_info = get_invite_code(code)
    if invite_info and invite_info.get('account_expires_days'):
        return int(invite_info['account_expires_days'])
    return 365  # 默认365天
```

### 2. 激活码使用记录

**数据库表：`invite_code_usage`**

**字段：**
- `id`：记录ID
- `invite_code_id`：邀请码ID（外键）
- `invite_code`：邀请码
- `user_id`：用户ID
- `openid`：微信OpenID
- `account_expires_at`：账号过期时间
- `used_at`：使用时间

**记录逻辑：**
```python
# application/routes/miniprogram.py
# 激活成功后记录使用
record_invite_code_usage(invite_code, user_id, openid, expires_at)
```

## 🔍 数据库结构

### invite_codes 表

```sql
CREATE TABLE invite_codes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    code VARCHAR(50) NOT NULL UNIQUE,
    created_by VARCHAR(100) NULL,
    max_uses INT DEFAULT 1,
    used_count INT DEFAULT 0,
    expires_at DATETIME NULL COMMENT '邀请码过期时间',
    account_expires_days INT DEFAULT 365 COMMENT '账号有效期（天数）',
    is_active BOOLEAN DEFAULT TRUE,
    notes TEXT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### invite_code_usage 表

```sql
CREATE TABLE invite_code_usage (
    id INT AUTO_INCREMENT PRIMARY KEY,
    invite_code_id INT NOT NULL COMMENT '邀请码ID',
    invite_code VARCHAR(50) NOT NULL COMMENT '邀请码',
    user_id INT NOT NULL COMMENT '用户ID',
    openid VARCHAR(128) NOT NULL COMMENT '微信OpenID',
    account_expires_at DATETIME NOT NULL COMMENT '账号过期时间',
    used_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '使用时间',
    
    INDEX idx_invite_code (invite_code),
    INDEX idx_user_id (user_id),
    INDEX idx_openid (openid),
    INDEX idx_used_at (used_at),
    FOREIGN KEY (invite_code_id) REFERENCES invite_codes(id) ON DELETE CASCADE
);
```

## 🔄 完整流程

### 1. 创建激活码

```
管理员创建激活码
    ↓
设置 account_expires_days (1/7/30/365)
    ↓
保存到数据库
```

### 2. 用户激活

```
用户输入激活码
    ↓
验证激活码有效性
    ↓
读取 account_expires_days
    ↓
激活用户（设置 expires_at = now + account_expires_days）
    ↓
记录使用记录（invite_code_usage）
    ↓
增加使用次数（used_count + 1）
```

### 3. 查看使用记录

```
管理员查看使用记录
    ↓
查询 invite_code_usage 表
    ↓
显示：用户ID、OpenID、账号过期时间、使用时间
```

## 📝 注意事项

1. **数据库迁移**：
   - 如果表已存在，需要手动添加 `account_expires_days` 字段
   - 已存在的激活码默认 `account_expires_days = 365`

2. **使用记录**：
   - 每次激活都会记录
   - 记录包含用户ID、OpenID、账号过期时间、使用时间

3. **有效期计算**：
   - 账号过期时间 = 激活时间 + account_expires_days
   - 存储在 `miniprogram_users.expires_at` 字段
