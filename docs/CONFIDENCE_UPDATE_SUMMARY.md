## 技术细节

### 受注力规则值更新
受注力值完全按照用户提供的表格配置，共更新了37个开盘区间规则：
- 每个规则包含9个信心等级的受注力值
- **特殊处理："信心中庸"包含两个值**
  - `lower`: 当双方都是信心中庸且我方分数 < 对手分数时使用
  - `higher`: 当双方都是信心中庸且我方分数 > 对手分数时使用
  - 如果对手不是信心中庸，默认使用 `lower` 值

### 受注力计算逻辑
前端 `getBettingPressureInfo()` 函数支持动态判断：
```javascript
// 当双方都是信心中庸时，比较分数决定使用哪个值
if (normalizedConfidence === '信心中庸' && normalizedOpponentConfidence === '信心中庸') {
    if (myScore < opponentScore) {
        value = value.lower;  // 分数低于对手
    } else {
        value = value.higher; // 分数高于对手
    }
}
```
