# 网页密码保护说明

## ✅ 已完成的修改

已为网页访问添加密码保护，同时确保API接口（小程序）正常访问。

## 🔧 修改内容

### 1. 创建密码保护装饰器

在 `application/routes/web.py` 中新增 `web_password_required` 装饰器：
- 检查 session 中是否已通过密码验证
- 如果是 POST 请求，验证密码
- 如果密码正确，设置 session 并允许访问
- 如果密码错误，显示错误信息

### 2. 修改网页路由

- **首页 (`/`)**：添加密码保护
- **旧版首页 (`/old`)**：添加密码保护
- **健康检查 (`/health`)**：不受影响（无需密码）
- **所有 API 路由 (`/api/*`)**：不受影响（小程序正常使用）
- **小程序路由 (`/api/miniprogram/*`)**：不受影响（正常使用）

### 3. 创建密码输入页面

创建了 `templates/password_protected.html` 模板：
- 美观的密码输入界面
- 密码验证功能
- 错误提示

## 🔑 密码配置

**默认密码**：`oddsmind2024`

**修改密码**：
可以通过环境变量 `WEB_ACCESS_PASSWORD` 设置自定义密码：

```bash
# 在 oddsmind.env 文件中添加：
WEB_ACCESS_PASSWORD=你的自定义密码
```

或者在启动应用时设置：
```bash
export WEB_ACCESS_PASSWORD=你的自定义密码
python app.py
```

## 📋 访问规则

### ✅ 需要密码的页面
- `/` - 首页
- `/old` - 旧版首页

### ✅ 不需要密码的接口（正常访问）
- `/health` - 健康检查
- `/api/*` - 所有API接口（小程序使用）
- `/api/miniprogram/*` - 小程序认证接口
- `/api/public/*` - 公共API接口

## 🔐 使用方式

1. **访问网页**：访问 `http://your-domain/` 或 `http://your-domain/old`
2. **输入密码**：在密码输入页面输入密码（默认：`oddsmind2024`）
3. **验证通过**：密码正确后，session 会保存验证状态，后续访问无需再次输入
4. **小程序访问**：小程序和API接口不受影响，正常使用

## 🛡️ 安全说明

1. **Session 存储**：密码验证状态存储在 session 中
2. **Session 持久化**：设置了 `session.permanent = True`，验证状态会保持一段时间
3. **密码验证**：当前使用简单字符串比较，如需更高安全性，可以改为哈希比较

## 🔄 清除访问权限

如果需要清除已保存的访问权限，可以：
1. 清除浏览器 cookies（删除 session）
2. 或者重启应用（session 会失效）

## 📝 注意事项

1. **API接口不受影响**：所有 `/api/` 开头的接口都不需要网页密码
2. **小程序正常使用**：小程序的所有接口都正常工作
3. **健康检查可用**：`/health` 接口无需密码，可用于监控
4. **密码修改**：修改密码后需要重启应用才能生效
