# 前端适配快速指南

## 🚨 必须立即修改的内容

### 1. 所有 API 请求必须添加 Token

```javascript
// ❌ 错误：缺少 Token
axios.get('/api/matches/today')

// ✅ 正确：添加 Authorization 头
axios.get('/api/matches/today', {
  headers: {
    'Authorization': `Bearer ${localStorage.getItem('token')}`
  }
})
```

### 2. 401 错误统一处理

```javascript
// 在 axios 拦截器中添加
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      // 清除 Token
      localStorage.removeItem('token');
      // 跳转登录
      router.push('/login');
    }
    return Promise.reject(error);
  }
);
```

### 3. 登录接口响应处理

```javascript
// 登录接口现在可能返回三种情况：

// 情况1：未激活 (status: 200)
{
  "success": true,
  "data": {
    "is_activated": false,
    "status": "NOT_ACTIVATED"
  }
}
// → 显示激活界面

// 情况2：账号过期 (status: 403)
{
  "success": false,
  "error_code": "EXPIRED_TOKEN",
  "expires_at": "2024-11-20T10:00:00+00:00"
}
// → 显示过期提示，引导重新激活

// 情况3：登录成功 (status: 200)
{
  "success": true,
  "data": {
    "token": "...",
    "user": {
      "is_activated": true,
      "expires_at": "2024-12-31T23:59:59+00:00"
    }
  }
}
// → 保存 Token 和用户信息
```

### 4. 激活接口错误码处理

```javascript
// 激活失败时的错误码：

// ALREADY_ACTIVATED - 账号已激活
if (error_code === 'ALREADY_ACTIVATED') {
  // 提示已激活，引导登录
}

// INVALID_INVITE_CODE - 激活码无效
if (error_code === 'INVALID_INVITE_CODE') {
  // 显示错误，允许重试
}
```

## 📋 错误码对照表

| 错误码 | HTTP 状态码 | 含义 | 前端操作 |
|--------|------------|------|---------|
| `AUTH_REQUIRED` | 401 | 需要登录 | 跳转登录页 |
| `INVALID_TOKEN` | 401 | Token 无效 | 跳转登录页 |
| `NOT_ACTIVATED` | 200 | 未激活 | 显示激活界面 |
| `EXPIRED_TOKEN` | 403 | 账号过期 | 显示过期提示 |
| `ALREADY_ACTIVATED` | 400 | 已激活 | 提示已激活 |
| `INVALID_INVITE_CODE` | 400 | 激活码无效 | 显示错误 |
