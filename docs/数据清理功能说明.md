# 数据清理功能说明

## 📋 功能概述

为防止分析数据表无限增长，系统新增了**自动数据清理**功能，定期删除7天以前的旧数据。

---

## 🎯 清理范围

### **清理的表**
1. **odds_analysis_results** - 赔率分析结果表
2. **fundamental_analysis** - 基本面分析表

### **清理规则**
- 保留最近 **7天** 的数据
- 根据比赛时间（match_time）判断，不是根据分析时间
- 通过 JOIN matches 表来获取比赛时间

### **不清理的表**
- `matches` - 比赛基础数据
- `odds_changes` - 赔率变化记录
- `european_odds` - 欧赔数据
- `general_strength` - 广义实力数据
- 其他基础数据表

---

## ⏰ 执行计划

### **定时任务**
- **执行时间**：每天凌晨 **03:00**
- **任务ID**：`daily_data_cleanup`
- **任务名称**：每日数据清理

### **完整的定时任务计划**
| 时间 | 任务 | 说明 |
|------|------|------|
| 23:59 | 联赛数据更新 | 更新比赛信息 |
| 00:59 | 赔率数据更新 | 更新赔率数据 |
| 01:59 | 广义实力计算 | 计算球队实力 |
| **03:00** | **数据清理** | **删除7天前的分析数据** |

## 🔧 SQL 清理逻辑

### **清理赔率分析**
```sql
DELETE oar FROM odds_analysis_results oar
INNER JOIN matches m ON oar.match_id = m.match_id
WHERE m.match_time < DATE_SUB(NOW(), INTERVAL 7 DAY)
```

### **清理基本面分析**
```sql
DELETE fa FROM fundamental_analysis fa
INNER JOIN matches m ON fa.match_id = m.match_id
WHERE m.match_time < DATE_SUB(NOW(), INTERVAL 7 DAY)
```

### **为什么使用 JOIN？**
- 分析表中没有直接的比赛时间字段
- 通过 JOIN matches 表获取准确的比赛时间
- 确保只删除真正过期的数据

### **SQL 查询统计**
```sql
-- 赔率分析结果统计
SELECT 
    COUNT(DISTINCT match_id) as match_count,
    COUNT(*) as record_count,
    MIN(analyzed_at) as earliest_analysis,
    MAX(analyzed_at) as latest_analysis
FROM odds_analysis_results;

-- 基本面分析统计
SELECT 
    COUNT(*) as record_count,
    MIN(updated_at) as earliest_analysis,
    MAX(updated_at) as latest_analysis
FROM fundamental_analysis;

-- 按日期分组统计
SELECT 
    DATE(m.match_time) as match_date,
    COUNT(DISTINCT oar.match_id) as match_count,
    COUNT(*) as record_count
FROM odds_analysis_results oar
JOIN matches m ON oar.match_id = m.match_id
GROUP BY DATE(m.match_time)
ORDER BY match_date DESC;
```

## 📌 注意事项

### **1. 数据安全**
- ⚠️ **删除操作不可恢复**
- 建议先在测试环境验证
- 可以先备份数据库

### **2. 性能影响**
- 删除操作使用 JOIN，可能较慢
- 选择在凌晨3点执行，业务低峰期
- 如果数据量大，可能需要几分钟

### **3. 索引建议**
```sql
-- 为提高清理性能，确保有以下索引

-- odds_analysis_results 表
ALTER TABLE odds_analysis_results 
ADD INDEX idx_match_id (match_id);

-- fundamental_analysis 表
ALTER TABLE fundamental_analysis 
ADD INDEX idx_match_id (match_id);

-- matches 表（应该已有）
ALTER TABLE matches 
ADD INDEX idx_match_time (match_time);
```

### **4. 监控建议**
- 定期检查日志：`logs/oddsmind.log`
- 监控表大小变化
- 关注清理任务执行时间
