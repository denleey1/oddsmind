### 3. **JWT Token 设计建议**

#### Token 结构
```python
{
    "user_id": 123,           # 用户ID
    "openid": "xxx",          # OpenID（用于验证）
    "is_activated": true,     # 激活状态
    "expires_at": "2024-12-31T23:59:59",  # 账号过期时间
    "iat": 1234567890,        # 签发时间
    "exp": 1234571490         # Token过期时间（建议7天）
}
```

#### Token 有效期策略
- **Token 有效期**：7天（可配置）
- **账号有效期**：由邀请码决定，存储在用户表中
- **刷新机制**：Token 过期前可以刷新，但账号过期后无法刷新

#### 安全建议
- ✅ 使用强密钥（至少32字符）
- ✅ Token 存储在 `httpOnly` cookie 或小程序本地存储
- ✅ 实现 Token 刷新机制
- ✅ 支持 Token 黑名单（可选，用于强制登出）

### 4. **`login_required` 装饰器增强建议**

#### 建议实现（向后兼容）

```python
def login_required(f):
    """
    增强的登录验证装饰器
    支持多种认证方式（优先级从高到低）：
    1. JWT Token（小程序）
    2. Session（Web端，如果将来启用）
    3. 直接通过（当前默认行为）
    """
    @wraps(f)
    def decorated_function(*args, **kwargs):
        from flask import request, g, session, jsonify
        
        # 1. 尝试 JWT Token 验证（小程序）
        jwt_token = _get_bearer_token(request)
        if jwt_token:
            jwt_user = _verify_jwt_token(jwt_token)
            if jwt_user:
                # 检查账号是否过期
                if jwt_user.get('expires_at') and datetime.fromisoformat(jwt_user['expires_at']) < datetime.now():
                    if request.path.startswith('/api/'):
                        return jsonify({"success": False, "error": "账号已过期"}), 401
                    return redirect("/login?error=expired")
                
                g.current_user = jwt_user
                return f(*args, **kwargs)
        
        # 2. 尝试 Session 验证（Web端，如果将来启用）
        # 当前可以保留但暂时不启用
        # if "user" in session:
        #     g.current_user = session.get("user")
        #     return f(*args, **kwargs)
        
        # 3. 默认行为：直接通过（保持向后兼容）
        # 如果将来需要启用认证，可以在这里添加重定向逻辑
        return f(*args, **kwargs)
    
    return decorated_function
```

**关键点：**
- ✅ 保持向后兼容，默认直接通过
- ✅ 支持 JWT 验证（小程序）
- ✅ 支持 Session 验证（Web端，预留）
- ✅ 检查账号过期时间
- ✅ 使用 Flask `g` 对象传递用户信息

### 6. **微信登录流程安全建议**

#### 当前流程
1. 小程序调用 `wx.login()` 获取 `code`
2. 后端调用微信 API 换取 `openid`
3. 后端验证用户状态并返回 Token

#### 安全建议
- ✅ **验证 code 有效性**：code 只能使用一次，5分钟内有效
- ✅ **防止重放攻击**：记录已使用的 code，防止重复使用
- ✅ **限制请求频率**：防止暴力破解
- ✅ **验证 openid 格式**：确保 openid 符合微信规范

#### 微信 API 调用
```python
import requests

def get_openid_from_wechat(code: str) -> dict:
    """
    通过 code 获取 openid
    需要配置微信小程序的 AppID 和 AppSecret
    """
    appid = os.environ.get('WECHAT_APPID')
    secret = os.environ.get('WECHAT_APPSECRET')
    
    url = f"https://api.weixin.qq.com/sns/jscode2session"
    params = {
        'appid': appid,
        'secret': secret,
        'js_code': code,
        'grant_type': 'authorization_code'
    }
    
    response = requests.get(url, params=params, timeout=5)
    data = response.json()
    
    if 'errcode' in data:
        raise ValueError(f"微信API错误: {data.get('errmsg')}")
    
    return {
        'openid': data.get('openid'),
        'session_key': data.get('session_key'),  # 注意：不要返回给前端
        'unionid': data.get('unionid')  # 可选
    }
```

## ⚠️ 潜在风险及应对

### 1. **微信 API 限制**
- **风险**：微信 API 有调用频率限制
- **应对**：实现请求缓存，避免重复调用

### 2. **Token 泄露**
- **风险**：Token 泄露可能导致账号被盗用
- **应对**：
  - 使用 HTTPS
  - Token 设置合理过期时间
  - 实现 Token 黑名单机制

### 3. **邀请码泄露**
- **风险**：邀请码泄露可能导致未授权用户注册
- **应对**：
  - 限制每个邀请码使用次数
  - 设置邀请码过期时间
  - 记录邀请码使用日志

### 4. **账号过期处理**
- **风险**：用户账号过期后无法使用
- **应对**：
  - 提前提醒用户（如过期前7天）
  - 提供续费/续期机制
  - 优雅的错误提示
