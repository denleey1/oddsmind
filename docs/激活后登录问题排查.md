# 激活后登录问题排查指南

## 🔍 问题现象

激活成功，但登录不进去。

## 🐛 可能的原因

### 1. Token 未正确保存

**症状：** 激活成功后，token 没有保存到本地存储

**检查方法：**
在小程序开发者工具中：
1. 打开"存储"面板
2. 查看是否有 `jwt_token` 键
3. 查看是否有 `user_info` 键

**修复：** 确保 `auth.activate()` 正确保存 token

### 2. Token 格式问题

**症状：** Token 保存了，但格式不正确

**检查方法：**
```javascript
// 在小程序中检查
const token = wx.getStorageSync('jwt_token')
console.log('Token:', token)
console.log('Token类型:', typeof token)
console.log('Token长度:', token ? token.length : 0)
```

**修复：** 确保 token 是字符串格式

### 3. 激活后未更新用户状态

**症状：** 激活成功后，前端状态没有更新

**检查方法：**
```javascript
// 检查用户信息
const userInfo = wx.getStorageSync('user_info')
console.log('用户信息:', userInfo)
console.log('是否激活:', userInfo?.is_activated)
```

**修复：** 确保激活成功后更新用户状态

### 4. 首页登录检查逻辑问题

**症状：** 首页检查登录状态时，发现 token 无效

**检查方法：** 查看首页的登录检查逻辑

**修复：** 确保首页正确检查 token 和用户状态

### 步骤2: 检查前端代码

**检查 `utils/auth.js` 中的 `activate()` 方法：**

```javascript
async activate(inviteCode) {
  try {
    const loginRes = await this.wxLogin()
    const code = loginRes.code

    const response = await api.post('/miniprogram/activate', {
      code,
      invite_code: inviteCode
    })

    console.log('激活接口响应:', response)  // ✅ 添加日志

    if (!response.success) {
      throw new Error(response.error || '激活失败')
    }

    const data = response.data
    console.log('激活接口数据:', data)  // ✅ 添加日志

    // ✅ 确保正确保存 token
    if (data.token) {
      storage.set(TOKEN_KEY, data.token)
      console.log('Token已保存:', data.token.substring(0, 20) + '...')  // ✅ 添加日志
    } else {
      console.error('激活接口未返回token!')  // ✅ 添加日志
    }

    // ✅ 确保正确保存用户信息
    if (data.user) {
      storage.set(USER_INFO_KEY, data.user)
      console.log('用户信息已保存:', data.user)  // ✅ 添加日志
    } else {
      console.error('激活接口未返回用户信息!')  // ✅ 添加日志
    }

    return {
      success: true,
      user: data.user,
      token: data.token
    }
  } catch (error) {
    console.error('激活失败:', error)
    return {
      success: false,
      error: error.message || '激活失败，请检查邀请码是否正确'
    }
  }
}
```

### 步骤3: 检查登录页面代码

**检查 `pages/login/login.js` 中的激活成功处理：**

```javascript
async onSubmitActivate() {
  const inviteCode = this.data.inviteCode.trim()

  if (!inviteCode) {
    wx.showToast({
      title: '请输入邀请码',
      icon: 'none'
    })
    return
  }

  this.setData({ loading: true, errorMessage: '' })

  try {
    const result = await auth.activate(inviteCode)
    
    console.log('激活结果:', result)  // ✅ 添加日志

    if (result.success) {
      // ✅ 验证 token 是否已保存
      const token = auth.getToken()
      console.log('激活后Token:', token ? '已保存' : '未保存')  // ✅ 添加日志
      
      // ✅ 验证用户信息是否已保存
      const userInfo = auth.getUserInfoSync()
      console.log('激活后用户信息:', userInfo)  // ✅ 添加日志

      wx.showToast({
        title: '激活成功',
        icon: 'success'
      })
      
      // ✅ 延迟跳转，确保数据已保存
      setTimeout(() => {
        // ✅ 再次验证登录状态
        if (auth.isLoggedIn() && auth.isActivated()) {
          console.log('登录状态验证通过，跳转首页')  // ✅ 添加日志
          this.redirectToHome()
        } else {
          console.error('登录状态验证失败，重新登录')  // ✅ 添加日志
          // 重新登录
          this.autoLogin()
        }
      }, 1500)
    } else {
      this.setData({
        loading: false,
        errorMessage: result.error || '激活失败，请检查邀请码'
      })
      wx.showToast({
        title: result.error || '激活失败',
        icon: 'none'
      })
    }
  } catch (error) {
    console.error('激活异常:', error)  // ✅ 添加日志
    this.setData({
      loading: false,
      errorMessage: error.message || '激活失败，请稍后重试'
    })
    wx.showToast({
      title: '激活失败',
      icon: 'none'
    })
  }
}
```

## 🔍 常见问题

### Q1: 激活成功后，为什么登录不进去？

**A:** 可能的原因：
1. Token 未正确保存
2. 用户信息未正确保存
3. 首页登录检查逻辑有问题
4. Token 格式不正确

**解决：** 按照上述步骤添加日志，检查每个环节

### Q2: 如何验证 Token 是否有效？

**A:** 可以调用用户信息接口验证：

```javascript
// 测试 Token 是否有效
const api = require('../../utils/api.js')

async function testToken() {
  try {
    const response = await api.get('/miniprogram/user')
    console.log('Token有效，用户信息:', response)
    return true
  } catch (error) {
    console.error('Token无效:', error)
    return false
  }
}
```

### Q3: 激活成功后，应该做什么？

**A:** 激活成功后应该：
1. ✅ 保存 Token 到本地存储
2. ✅ 保存用户信息到本地存储
3. ✅ 更新前端登录状态
4. ✅ 跳转到首页或重新调用登录接口

## 🛠️ 修复建议

### 修复1: 确保激活后正确保存数据

在 `utils/auth.js` 的 `activate()` 方法中：

```javascript
async activate(inviteCode) {
  try {
    const loginRes = await this.wxLogin()
    const code = loginRes.code

    const response = await api.post('/miniprogram/activate', {
      code,
      invite_code: inviteCode
    })

    if (!response.success) {
      throw new Error(response.error || '激活失败')
    }

    const data = response.data

    // ✅ 确保保存 token
    if (data.token) {
      storage.set(TOKEN_KEY, data.token)
    } else {
      console.error('激活接口未返回token')
      throw new Error('激活失败：未返回token')
    }

    // ✅ 确保保存用户信息
    if (data.user) {
      storage.set(USER_INFO_KEY, data.user)
    } else {
      console.error('激活接口未返回用户信息')
      throw new Error('激活失败：未返回用户信息')
    }

    return {
      success: true,
      user: data.user,
      token: data.token
    }
  } catch (error) {
    console.error('激活失败:', error)
    return {
      success: false,
      error: error.message || '激活失败，请检查邀请码是否正确'
    }
  }
}
```

### 修复2: 激活成功后重新登录

在 `pages/login/login.js` 中：

```javascript
async onSubmitActivate() {
  // ... 激活逻辑 ...

  if (result.success) {
    wx.showToast({
      title: '激活成功',
      icon: 'success'
    })
    
    // ✅ 激活成功后，重新调用登录接口，确保获取最新的token

      try {
        const loginResult = await auth.login()
        if (loginResult.success) {
          this.redirectToHome()

        wx.showToast({
          title: '登录失败，请重试',
          icon: 'none'
        })
      }
    }, 1500)
  }
}
```
