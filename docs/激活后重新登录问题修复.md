# 激活后重新登录问题修复

## 🔍 问题分析

**现象：**
- 激活成功，token和用户信息都已保存
- 激活后验证：Token已保存，用户信息已保存，is_activated: true
- 重新登录时返回：`{success: false, needActivate: true, openid: undefined, message: "需要激活账号"}`

**后端日志显示：**
- 登录检查: `is_activated=1` ✅
- 登录成功 ✅

**问题根源：**
前端重新登录时，可能使用了**已过期或无效的微信code**，导致获取openid失败，或者获取到了不同的openid。

## ✅ 解决方案

### 方案1: 激活成功后不重新登录（推荐）

既然激活接口已经返回了token和用户信息，并且已经保存成功，就不需要重新调用登录接口了。

**修改 `pages/login/login.js`：**

```javascript
async onSubmitActivate() {
  const inviteCode = this.data.inviteCode.trim()

  if (!inviteCode) {
    wx.showToast({
      title: '请输入邀请码',
      icon: 'none'
    })
    return
  }

  this.setData({ loading: true, errorMessage: '' })

  try {
    console.log('开始激活，邀请码:', inviteCode)
    const result = await auth.activate(inviteCode)
    console.log('激活结果:', result)

    if (result.success) {
      // ✅ 验证 token 是否已保存
      const token = auth.getToken()
      const userInfo = auth.getUserInfoSync()
      
      console.log('激活后验证 - Token:', token ? '已保存' : '未保存')
      console.log('激活后验证 - 用户信息:', userInfo)
      console.log('激活后验证 - 是否激活:', userInfo?.is_activated)

      if (!token || !userInfo) {
        console.error('激活后数据未保存，重新登录')
        // 数据未保存，重新登录
        setTimeout(() => {
          this.autoLogin()
        }, 1000)
        return
      }

      // ✅ 验证用户是否已激活
      if (!userInfo.is_activated) {
        console.error('激活后用户状态未更新，重新登录')
        setTimeout(() => {
          this.autoLogin()
        }, 1000)
        return
      }

      wx.showToast({
        title: '激活成功',
        icon: 'success'
      })
      
      // ✅ 激活成功，直接跳转（不需要重新登录）
      setTimeout(() => {
        console.log('激活成功，直接跳转首页')
        this.redirectToHome()
      }, 1500)
    } else {
      this.setData({
        loading: false,
        errorMessage: result.error || '激活失败，请检查邀请码'
      })
      wx.showToast({
        title: result.error || '激活失败',
        icon: 'none'
      })
    }
  } catch (error) {
    console.error('激活异常:', error)
    this.setData({
      loading: false,
      errorMessage: error.message || '激活失败，请稍后重试'
    })
    wx.showToast({
      title: '激活失败',
      icon: 'none'
    })
  }
}
```

### 方案2: 如果必须重新登录，确保使用新的code

如果确实需要重新登录，确保每次调用 `wx.login()` 获取新的code：

```javascript
async onSubmitActivate() {
  // ... 激活逻辑 ...

  if (result.success) {
    wx.showToast({
      title: '激活成功',
      icon: 'success'
    })
    
    // ✅ 如果需要重新登录，确保获取新的code
    setTimeout(async () => {
      try {
        console.log('激活成功，重新登录...')
        
        // ✅ 重新获取新的code（重要！）
        const loginRes = await auth.wxLogin()
        const code = loginRes.code
        console.log('重新获取code:', code ? '成功' : '失败')
        
        if (!code) {
          console.error('无法获取新的code')
          // 如果无法获取新code，但token已保存，直接跳转
          if (auth.isLoggedIn() && auth.isActivated()) {
            this.redirectToHome()
          }
          return
        }
        
        // 使用新code重新登录
        const loginResult = await auth.login()
        console.log('重新登录结果:', loginResult)
        
        if (loginResult.success) {
          console.log('重新登录成功，跳转首页')
          this.redirectToHome()
        } else {
          console.error('重新登录失败:', loginResult.error)
          // 如果重新登录失败，但token已保存，直接跳转
          if (auth.isLoggedIn() && auth.isActivated()) {
            console.log('Token已保存，直接跳转')
            this.redirectToHome()
          } else {
            wx.showToast({
              title: loginResult.error || '登录失败，请重试',
              icon: 'none'
            })
          }
        }
      } catch (error) {
        console.error('重新登录异常:', error)
        // 如果重新登录失败，但token已保存，直接跳转
        if (auth.isLoggedIn() && auth.isActivated()) {
          console.log('Token已保存，直接跳转')
          this.redirectToHome()
        } else {
          wx.showToast({
            title: '登录失败，请重试',
            icon: 'none'
          })
        }
      }
    }, 1500)
  }
}
```

### 方案3: 修改登录接口，支持使用已保存的token

如果前端已经有token，可以直接使用token获取用户信息，不需要重新调用登录接口：

```javascript
// 在 auth.js 中添加方法
async checkLoginStatus() {
  const token = this.getToken()
  const userInfo = this.getUserInfoSync()
  
  if (!token || !userInfo) {
    return { success: false, needLogin: true }
  }
  
  // 使用token获取最新用户信息
  try {
    const response = await api.get('/miniprogram/user')
    if (response.success) {
      // 更新用户信息
      storage.set(USER_INFO_KEY, response.data)
      return {
        success: true,
        user: response.data,
        token: token
      }
    }
  } catch (error) {
    console.error('检查登录状态失败:', error)
    // Token可能已过期，清除本地数据
    this.logout()
    return { success: false, needLogin: true }
  }
  
  return {
    success: true,
    user: userInfo,
    token: token
  }
}
```

然后在激活成功后：

```javascript
if (result.success) {
  wx.showToast({
    title: '激活成功',
    icon: 'success'
  })
  
  setTimeout(async () => {
    // ✅ 使用已保存的token检查登录状态
    const status = await auth.checkLoginStatus()
    if (status.success) {
      this.redirectToHome()
    } else {
      // 如果检查失败，重新登录
      this.autoLogin()
    }
  }, 1500)
}
```

## 🎯 推荐方案

**推荐使用方案1**：激活成功后直接跳转，不需要重新登录。

**原因：**
1. 激活接口已经返回了token和用户信息
2. 数据已经保存到本地存储
3. 重新登录可能因为code过期导致失败
4. 不需要额外的网络请求

---

## 🔍 问题根源

**为什么重新登录会失败？**

1. **微信code只能使用一次**：激活时已经使用了一次code，重新登录时如果使用相同的code会失败
2. **code有效期5分钟**：如果激活和重新登录之间间隔较长，code可能已过期
3. **需要获取新的code**：每次调用登录接口都需要新的code

**解决方案：**
- ✅ 激活成功后直接跳转（推荐）
- ✅ 或者重新获取新的code再登录
- ✅ 或者使用已保存的token检查登录状态
