# 激活码使用限制说明

## ✅ 当前实现

### 1. 激活码使用次数限制

**数据库字段：**
- `max_uses`：最大使用次数（默认1）
- `used_count`：已使用次数（默认0）

**验证逻辑：**
```python
# utils/miniprogram_db.py
def validate_invite_code(code: str):
    invite_info = get_invite_code(code)
    
    # 检查使用次数
    if invite_info['used_count'] >= invite_info['max_uses']:
        return False, "邀请码使用次数已达上限"
    
    return True, None
```

**使用逻辑：**
```python
# 激活成功后，增加使用次数
use_invite_code(invite_code)
```

### 2. 用户激活状态持久化

**数据库字段：**
- `is_activated`：是否已激活（BOOLEAN）
- `activated_at`：激活时间
- `expires_at`：账号过期时间
- `invite_code_used`：使用的邀请码

**激活逻辑：**
```python
# utils/miniprogram_db.py
def activate_user(openid: str, invite_code: str, expires_days: int = 365):
    expires_at = datetime.now() + timedelta(days=expires_days)
    
    sql = """
        UPDATE miniprogram_users
        SET is_activated = TRUE,
            activated_at = NOW(),
            expires_at = %s,
            invite_code_used = %s
        WHERE openid = %s
    """
    execute_update(sql, (expires_at, invite_code, openid))
```

**登录检查：**
```python
# application/routes/miniprogram.py
# 检查是否已激活
is_activated = bool(user.get('is_activated'))

if not is_activated:
    return api_success({
        'openid': openid,
        'is_activated': False,
        'message': '需要激活账号'
    })

# 已激活，返回token
return api_success({
    'token': token,
    'user': {
        'is_activated': True,
        ...
    }
})
```

**优化建议：使用事务确保原子性**

```python
from app_database import get_connection

def activate_user_with_invite_code(openid: str, invite_code: str, expires_days: int):
    """原子性操作：激活用户并使用邀请码"""
    conn = get_connection()
    try:
        with conn.cursor() as cursor:
            # 1. 验证邀请码（在事务中）
            cursor.execute("""
                SELECT max_uses, used_count, is_active, expires_at
                FROM invite_codes
                WHERE code = %s FOR UPDATE
            """, (invite_code,))
            
            invite_info = cursor.fetchone()
            if not invite_info:
                raise ValueError("邀请码不存在")
            
            if not invite_info['is_active']:
                raise ValueError("邀请码已被禁用")
            
            if invite_info['used_count'] >= invite_info['max_uses']:
                raise ValueError("邀请码使用次数已达上限")
            
            # 2. 激活用户
            expires_at = datetime.now() + timedelta(days=expires_days)
            cursor.execute("""
                UPDATE miniprogram_users
                SET is_activated = TRUE,
                    activated_at = NOW(),
                    expires_at = %s,
                    invite_code_used = %s
                WHERE openid = %s
            """, (expires_at, invite_code, openid))
            
            # 3. 使用邀请码
            cursor.execute("""
                UPDATE invite_codes
                SET used_count = used_count + 1
                WHERE code = %s
            """, (invite_code,))
            
            conn.commit()
            return True
    except Exception as e:
        conn.rollback()
        raise
    finally:
        conn.close()
```

