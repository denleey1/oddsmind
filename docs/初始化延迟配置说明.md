# 初始化延迟配置说明

## ✅ 已修改

初始化已改为**启动后10分钟**执行，避免每次重启服务都要等待初始化完成。

**修改时间：** 2025-11-16 02:18
**状态：** ✅ 已完成并验证

---

## 🔧 修改内容

### 修改文件
1. `application/bootstrap.py` - `auto_initialize()` 函数
2. `application/web/server.py` - `run_application()` 函数

### 修改内容
- **延迟时间**：从 2 秒改为 **600 秒（10分钟）**
- **移除立即初始化**：`run_application()` 中移除了立即调用 `initialize_application()`
- **统一延迟策略**：所有初始化路径都使用10分钟延迟

### 修改后的行为
1. 应用启动后立即可用（Flask 服务器立即启动）
2. 10 分钟后自动执行初始化
3. 初始化在后台线程中执行，不影响服务响应

---

## 📋 初始化包含的内容

初始化会执行以下操作（10分钟后）：
1. 启动定时任务调度器
2. 启动定时数据更新服务
3. 启动联赛状态监控服务
4. 分析现有赔率变化
5. 初始化每日监控

## ⚙️ 自定义延迟时间

如果需要修改延迟时间，编辑 `application/bootstrap.py`：

```python
def auto_initialize() -> None:
    def delayed_init():
        # 修改这里的延迟时间（秒）
        delay_seconds = 600  # 10分钟 = 600秒
        # delay_seconds = 300  # 5分钟 = 300秒
        # delay_seconds = 1800  # 30分钟 = 1800秒
        # delay_seconds = 3600  # 1小时 = 3600秒
        
        time.sleep(delay_seconds)
        # ...
```

## 📝 注意事项

1. **首次启动**：如果服务是首次启动，可能需要立即初始化
2. **手动初始化**：可以通过 API 手动触发初始化（如果需要在10分钟内初始化）
3. **定时任务**：定时任务调度器会在初始化时启动，但不会影响 Flask 服务

## 🎯 优势

1. ✅ **快速启动**：服务立即可用，无需等待
2. ✅ **不影响使用**：初始化在后台执行
3. ✅ **灵活配置**：可以随时修改延迟时间
