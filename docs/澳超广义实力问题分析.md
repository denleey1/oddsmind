### 1. 轮次数据问题 ⚠️

**位置**：`calculation/strength_service.py` 第49行

**代码**：

**潜在问题**：
- 如果 `round_number` 字段为 `NULL`，`max()` 可能返回 `NaN`
- 如果 `round_number` 字段缺失，会导致计算错误
- 澳超的轮次数据可能不完整或格式不正确

### 2. 数据过滤问题 ⚠️

**位置**：`calculation/strength_repository.py` 第56行

**代码**：

- 只计算已完成比赛的广义实力

- 需要检查澳超的 `match_status` 是否正确

### 3. 球队数量计算问题 ⚠️

**位置**：`calculation/strength_service.py` 第62-63行

**代码**：

### 4. 赔率数据覆盖问题 ⚠️

## 检查步骤

### 步骤1：检查比赛数据
```sql
SELECT 
    COUNT(*) as total_matches,
    COUNT(DISTINCT home_team_id) + COUNT(DISTINCT away_team_id) as unique_teams,
    COUNT(CASE WHEN match_status = 'finished' THEN 1 END) as finished_matches,
    COUNT(CASE WHEN round_number IS NULL THEN 1 END) as null_rounds,
    MIN(round_number) as min_round,
    MAX(round_number) as max_round,
    COUNT(DISTINCT round_number) as unique_rounds
FROM matches
WHERE league_id = 273
```

### 步骤2：检查赔率数据覆盖
```sql
SELECT 
    COUNT(DISTINCT m.match_id) as total_matches,
    COUNT(DISTINCT CASE WHEN eo.match_id IS NOT NULL THEN m.match_id END) as matches_with_odds,
    COUNT(DISTINCT eo.company_id) as companies_count
FROM matches m
LEFT JOIN european_odds eo ON eo.match_id = m.match_id
WHERE m.league_id = 273 AND m.match_status = 'finished'
```

### 步骤3：检查广义实力数据
```sql
SELECT 
    COUNT(DISTINCT tpr.company_id) as company_count,
    COUNT(DISTINCT tpr.team_id) as team_count,
    COUNT(*) as total_records,
    MIN(tpr.power_level) as min_power,
    MAX(tpr.power_level) as max_power,
    AVG(tpr.power_level) as avg_power
FROM team_power_ratings tpr
JOIN teams t ON t.team_id = tpr.team_id
JOIN matches m ON (m.home_team_id = t.team_id OR m.away_team_id = t.team_id)
WHERE m.league_id = 273
```

### 步骤4：检查轮次数据分布

## 可能的问题原因

1. **轮次数据不完整**：澳超的 `round_number` 字段可能有 NULL 值或缺失
2. **已完成比赛不足**：澳超可能有很多未完成的比赛，导致数据不足
3. **赔率数据覆盖不足**：澳超的赔率数据覆盖率可能低于80%，被跳过计算
4. **球队数量不对**：如果数据中球队数量不对，会影响近况轮次计算
5. **轮次数据格式问题**：轮次数据可能不是整数，导致计算错误

## 建议的修复方案

1. **检查并修复轮次数据**：确保所有比赛的 `round_number` 字段都有值
2. **检查赔率数据覆盖**：确保赔率数据覆盖率达到80%以上
3. **验证球队数量**：确保澳超的球队数量正确（12支）
4. **重新计算广义实力**：修复数据后，重新运行广义实力计算
