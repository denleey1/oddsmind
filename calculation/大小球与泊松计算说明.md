# 📊 大小球与泊松计算文件说明

## 🎯 核心计算文件

### 1. **`poisson_core.py`** - 泊松计算核心
**作用**: 泊松分布的基础计算逻辑
- ✅ 从MySQL加载比赛数据
- ✅ 计算联赛平均进球数
- ✅ 计算球队攻防实力（λ值）
- ✅ 比分概率矩阵计算
- ✅ 无UI依赖，纯计算逻辑

**主要函数**:
```python
- load_match_data(league_id)        # 加载比赛数据
- calculate_league_averages()        # 联赛平均进球
- calculate_team_strength()          # 球队λ值
- calculate_score_probabilities()    # 比分概率矩阵
```

---

### 2. **`poisson_predictor.py`** - 泊松预测器
**作用**: 基于历史数据的泊松预测
- ✅ 预测主客队进球数分布
- ✅ 计算各种比分概率
- ✅ 大小球、让球预测
- ✅ 半全场预测

**主要类**:
```python
class PoissonPredictor:
    def get_team_stats()              # 获取球队统计
    def calculate_lambda()            # 计算λ值
    def predict_match()               # 预测比赛
    def calculate_over_under()        # 大小球概率
```

**使用示例**:
```python
from calculation.poisson_predictor import PoissonPredictor

predictor = PoissonPredictor()
result = predictor.predict_match(
    home_team_id=123, 
    away_team_id=456, 
    league_id=36
)
```

---

### 3. **`ou_fold2p5.py`** - 大小球折算到2.5
**作用**: 将任意盘口的大小球赔率折算为2.5球的概率
- ✅ 支持亚洲盘（整数盘、半球盘、四分盘）
- ✅ 从赔率反推隐含λ值
- ✅ 折算到Over 2.5的概率
- ✅ 并发处理多条数据

**核心逻辑**:
1. 从大小球赔率提取无水位概率
2. 根据盘口类型计算EV方程
3. 二分法求解隐含λ值
4. 折算到2.5球的概率

**支持的盘口格式**:
```python
"2.5"     -> 2.5 (半球)
"2/2.5"   -> 2.25 (四分盘)
"2.5/3"   -> 2.75 (四分盘)
"3"       -> 3.0 (整数盘)
```

**使用方法**:
```bash
# 从SQLite读取ou_odds表，计算并输出
python calculation/ou_fold2p5.py \
    --db data/oddsmind.db \
    --out_rows ou_rows.csv \
    --out_consensus ou_consensus.csv \
    --workers 4
```

**输出结果**:
- `ou_rows.csv`: 每个博彩公司的μ、P(Over2.5)、P(0-7球)
- `ou_consensus.csv`: 每场比赛的共识概率

## 📂 数据流向

```
比赛数据（MySQL）
    ↓
[poisson_core.py]
    ↓
计算λ值、比分矩阵
    ↓
[poisson_predictor.py] → 预测结果
    ↓
[poisson_fusion.py] → 融合多源预测
    ↓
[ou_fold2p5.py] → 大小球折算

大小球赔率（ou_odds表）
    ↓
[ou_fold2p5.py]
    ↓
反推μ值、折算2.5概率
    ↓
ou_rows_metrics表
ou_consensus_metrics表
```

## 📊 关键概念

### λ (Lambda) - 泊松参数
表示预期进球数的期望值：
- **主队λ = 主队攻击力 × 客队防守弱点 × 主场优势**
- **客队λ = 客队攻击力 × 主队防守弱点**

### μ (Mu) - 总进球期望
- **μ = 主队λ + 客队λ**
- 用于计算大小球概率

### 计算流程
1. 从历史数据计算联赛平均进球
2. 计算球队攻防实力系数
3. 结合对手实力得出λ值
4. 使用泊松公式计算各比分概率
5. 累加得出大小球、让球等概率
