# 批量补充分析结果脚本使用说明

## 功能
批量补充有初盘数据但没有分析结果的比赛。

## 使用方法

### 1. 查看需要补充的数据量（试运行）
```bash
python3 scripts/batch_supplement_analysis.py --dry-run
```

### 2. 限制数量测试（先处理少量数据验证）
```bash
# 处理前10场比赛
python3 scripts/batch_supplement_analysis.py --limit 10 --workers 2

# 处理前100场比赛
python3 scripts/batch_supplement_analysis.py --limit 100 --workers 5
```

### 3. 批量处理所有数据
```bash
# 默认参数：并发5个线程，每批50场比赛
python3 scripts/batch_supplement_analysis.py

# 自定义参数：并发10个线程，每批100场比赛
python3 scripts/batch_supplement_analysis.py --workers 10 --batch-size 100
```

### 4. 后台运行（推荐用于大量数据）
```bash
# 使用nohup在后台运行，输出到日志文件
nohup python3 scripts/batch_supplement_analysis.py --workers 5 --batch-size 50 > batch_supplement.log 2>&1 &

# 查看进度
tail -f batch_supplement.log
```

## 参数说明

- `--limit N`: 限制处理的比赛数量（默认：不限制，处理所有）
- `--workers N`: 并发工作线程数（默认：5，建议根据服务器性能调整）
- `--batch-size N`: 每批处理的比赛数量（默认：50）
- `--dry-run`: 仅显示需要处理的比赛，不实际执行分析

## 性能建议

- **小规模测试**：`--limit 10 --workers 2`
- **中等规模**：`--limit 1000 --workers 5 --batch-size 50`
- **大规模处理**：`--workers 10 --batch-size 100`（后台运行）

## 注意事项

1. 脚本会自动跳过没有广义实力数据的公司（非联赛初期）
2. 处理大量数据时建议在后台运行
3. 脚本支持中断后继续（通过重新运行，已处理的会自动跳过）
4. 建议先小批量测试，确认无误后再处理全部数据
