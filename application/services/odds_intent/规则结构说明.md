# 欧赔意图分析规则结构说明

## 规则集版本
当前版本：`ruleset_v1.2`

## 阈值定义

| 阈值名称 | 值 | 说明 |
|---------|-----|------|
| `tao` | 0.08 (8%) | Δodds >= +8% 认为**韬**（抬赔阻信心） |
| `real` | -0.08 (-8%) | Δodds <= -8% 认为**实**（压赔降赔付） |
| `draw_spill_pp` | 0.02 (2pp) | Δp(D) >= +2pp 平局**分洪** |
| `draw_block_pp` | -0.02 (-2pp) | Δp(D) <= -2pp **阻平** |
| `move_confirm` | -0.03 (-3%) | Δmove <= -3% 认为"**确认走强**" |
| `move_reverse` | 0.03 (3%) | Δmove >= +3% 认为"**反做/诱导**" |

## 规则结构列表

### 1. DogReal+DrawSpill+FavTao（弱势实+平分洪+热门韬）

**匹配条件（全部满足）：**
- `delta_odds_live_dog <= real` （冷门方向压赔≤-8%）
- `delta_p_live_D >= draw_spill_pp` （平局Δp≥+2pp）
- `delta_odds_live_fav >= tao` （热门方向抬赔≥+8%）

**推荐结果：**
- `pick`: 冷门方向（{dog}）
- `hedge`: D（平局）
- `market_pick`: X2
- `confidence_base`: 72%
- `intent`: "弱势方向降赔付保护，平赔做分洪口，热门方向抬赔阻信心"

**解释：**
- 弱势方向压赔=降赔付保护
- 平局Δp为正=平做分洪口
- 热门方向抬赔=阻信心/诱导

- 冷门方向抬赔=阻信心/任人博取

- `delta_odds_live_fav <= real` （热门方向压赔≤-8%）
- `delta_p_live_D >= draw_spill_pp` （平局Δp≥+2pp）

**推荐结果：**
- `pick`: 热门方向（{fav}）

### 4. DrawBlock+EdgeReal（阻平+边实）

**匹配条件（全部满足）：**
- `delta_p_live_D <= draw_block_pp` （平局Δp≤-2pp，阻平）
- `(delta_odds_live_fav <= real or delta_odds_live_dog <= real)` （热门或冷门方向压赔≤-8%）

**推荐结果：**
- `pick`: fav_if_fav_real_else_dog（如果热门实则选热门，否则选冷门）
- `hedge`: none_or_small
- `market_pick`: 12（排除平局）
- `confidence_base`: 66%
- `intent`: "阻平拉边，结果倾向落在胜负一侧"

**解释：**
- 平局Δp为负=阻平
- 一侧压赔=倾向该侧

**匹配条件：**
- `1 == 1` （总是匹配，作为fallback）

- `hedge`: 1X2_mix

- `intent`: "基于概率偏移最大项判断"

**解释：**
- 未匹配到明确结构，基于Δp最大项判断

## 变量说明

### 计算特征变量

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `delta_odds_live_H` | 主胜即时赔率相对骨架的偏移 | 0.125 (12.5%) |
| `delta_odds_live_D` | 平局即时赔率相对骨架的偏移 | -0.173 (-17.3%) |
| `delta_odds_live_A` | 客胜即时赔率相对骨架的偏移 | -0.158 (-15.8%) |
| `delta_odds_live_fav` | 热门方向即时赔率偏移 | 自动识别H或A |
| `delta_odds_live_dog` | 冷门方向即时赔率偏移 | 自动识别H或A |
| `delta_p_live_H` | 主胜概率偏移（百分点） | -0.0732 (-7.32pp) |
| `delta_p_live_D` | 平局概率偏移（百分点） | 0.0395 (3.95pp) |
| `delta_p_live_A` | 客胜概率偏移（百分点） | 0.0337 (3.37pp) |
| `delta_move_H` | 主胜变盘幅度 | 0.023 (2.3%) |
| `delta_move_D` | 平局变盘幅度 | 0.036 (3.6%) |
| `delta_move_A` | 客胜变盘幅度 | -0.032 (-3.2%) |
| `fav` | 热门方向 | "H" 或 "A" |
| `dog` | 冷门方向 | "H" 或 "A" |

### 阈值变量

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `tao` | 0.08 | 韬阈值 |
| `real` | -0.08 | 实阈值 |
| `draw_spill_pp` | 0.02 | 平分洪阈值 |
| `draw_block_pp` | -0.02 | 阻平阈值 |
| `move_confirm` | -0.03 | 确认走强阈值 |
| `move_reverse` | 0.03 | 反做阈值 |

## 为什么总是匹配到Fallback规则？

如果总是匹配到 `FallbackByDeltaP` 规则，可能的原因：

1. **表达式求值失败**：simpleeval的API使用错误（已修复）
2. **数据不满足规则条件**：计算出的特征值不满足任何规则的条件
3. **阈值设置过严**：阈值设置可能导致规则难以匹配

## 如何查看当前计算的特征值？

在AI分析结果中，会显示：
- 骨架点：H、D、A的骨架值
- Δodds(即时)：H、D、A的即时赔率偏移百分比
- Δp(即时)：H、D、A的概率偏移百分点
- 变盘幅度：H、D、A的变盘百分比

根据这些值，可以判断是否符合某个规则的条件。
