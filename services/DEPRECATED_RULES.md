## 淘汰规则管理

### 如何淘汰规则

1. **识别表现不佳的规则**
   - 运行 `python services/rule_optimizer.py --analyze --days N`
   - 查看报告中的"表现不佳的规则"部分

2. **验证淘汰标准**
   - 实际准确率 < 理论准确率 - 15%
   - 样本数 >= 5（确保统计意义）
   - 准确率差异明显（> 15%）

3. **执行淘汰**
   - 在 `services/auto_rule_matcher.py` 中注释掉规则定义
   - 添加淘汰原因注释
   - 在本文件中记录淘汰信息
   - 更新规则定义顶部的更新日志

4. **重启服务**
   ```bash
   sudo systemctl restart auto_rule_matcher.service
   ```

### 淘汰标准

规则在以下情况下应被淘汰：

1. **表现不佳**
   - 实际准确率 < 理论准确率 - 15%
   - 样本数 >= 5

2. **持续下降**
   - 连续多次分析中表现不佳
   - 准确率持续下降趋势

3. **过拟合**
   - 训练集准确率很高，但测试集准确率明显下降
   - 准确率差异 > 10%

### 恢复规则

如果规则后续表现改善，可以恢复：

1. 取消注释规则定义
2. 更新规则准确率和样本数
3. 在本文件中添加恢复记录
4. 重启服务
